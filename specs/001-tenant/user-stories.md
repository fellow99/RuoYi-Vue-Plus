## 一、超级管理员视角

### US-001-001: 创建新租户

**作为** 超级管理员  
**我希望** 能够创建新的租户  
**以便于** 为企业客户开通系统使用权

**验收标准：**
- 填写企业名称、联系人、联系电话等基本信息
- 选择租户套餐（决定可用功能菜单）
- 设置用户数量限制（-1 表示不限制）
- 设置过期时间（可选，不填表示永久）
- 自动创建租户管理员账号（用户名、密码）
- 系统自动生成 6 位数字租户 ID
- 自动初始化租户的角色、部门、字典、参数

**测试场景：**
1. 正常创建租户 → 成功，生成租户 ID
2. 企业名称重复 → 提示"企业名称已存在"
3. 套餐名称不存在 → 提示"套餐不存在"
4. 管理员账号为空 → 提示"管理员账号不能为空"

### US-001-003: 修改租户信息

**作为** 超级管理员  
**我希望** 修改租户的基本信息  
**以便于** 更新企业联系方式或地址

**验收标准：**
- 可修改联系人、电话、地址、域名、企业简介
- 可更换租户套餐
- 企业名称不可修改（保证唯一性）
- 租户 ID 不可修改
- 修改后自动清除缓存

**测试场景：**
1. 修改联系人信息 → 成功保存
2. 更换套餐 → 成功，提示是否同步菜单
3. 修改企业名称 → 字段禁用，不可修改

---

### US-001-004: 停用/启用租户

**作为** 超级管理员  
**我希望** 停用或启用租户  
**以便于** 管理欠费或违规租户

**验收标准：**
- 可切换租户状态（0 正常/1 停用）
- 停用后租户用户无法登录
- 不允许停用默认租户（000000）
- 状态变更立即生效

**测试场景：**
1. 停用普通租户 → 成功，租户用户无法登录
2. 停用超管租户 → 提示"不允许操作管理租户"
3. 启用已停用租户 → 成功，租户用户可登录

---

## 四、业务场景故事

### Story-001-001: SaaS 平台开通新客户

**背景：** 某 SaaS 平台需要为一家新企业客户开通系统使用权

**流程：**
1. 销售与企业签订合同
2. 运维人员在系统中创建租户
   - 填写企业名称：XX 科技有限公司
   - 选择套餐：企业版（包含所有功能）
   - 设置用户数量：200
   - 设置过期时间：1 年后
   - 创建管理员账号：admin/密码
3. 系统自动生成租户 ID：000123
4. 系统自动初始化：
   - 创建管理员角色
   - 创建公司部门
   - 创建管理员用户
   - 同步字典和参数
5. 将管理员账号交付给客户
6. 客户登录系统，开始使用

**结果：** 新客户成功开通，可正常使用系统

---

### Story-001-002: 租户续费管理

**背景：** 某租户即将到期，需要续费

**流程：**
1. 系统检测到租户即将过期（提前 30 天）
2. 发送续费通知给租户管理员
3. 租户联系销售续费
4. 运维人员修改租户过期时间
5. 租户可继续使用系统

**结果：** 租户成功续费，服务不中断

---

### Story-001-003: 租户违规处理

**背景：** 某租户违反使用协议，需要停用

**流程：**
1. 客服收到投诉，确认租户违规
2. 运维人员停用该租户
3. 租户用户无法登录系统
4. 租户联系平台申诉
5. 问题解决后，运维人员启用租户

**结果：** 违规租户被及时处理，问题解决后恢复

---

### Story-001-004: 租户套餐升级

**背景：** 某租户业务增长，需要升级套餐

**流程：**
1. 租户联系销售升级套餐
2. 运维人员修改租户套餐
   - 从基础版升级到企业版
   - 同步菜单权限
3. 租户可访问更多功能

**结果：** 租户成功升级，可使用更多功能

## 五、验收标准汇总

### 功能验收

- [ ] 能够成功创建租户，自动生成租户 ID
- [ ] 创建租户时自动初始化角色、部门、用户
- [ ] 租户用户登录后只能看到本租户数据
- [ ] 超级管理员可以查看所有租户数据
- [ ] 支持停用/启用租户
- [ ] 支持删除租户（超管租户除外）
- [ ] 支持创建和修改租户套餐
- [ ] 套餐删除前校验是否被使用
- [ ] 支持动态切换租户
- [ ] 支持同步字典和参数到所有租户
- [ ] 支持导出租户数据

### 性能验收

- [ ] 租户列表查询响应时间 < 500ms
- [ ] 创建租户耗时 < 3s
- [ ] 租户数据隔离无泄漏
- [ ] 并发场景下租户上下文正确

### 安全验收

- [ ] 仅超级管理员可管理租户
- [ ] 租户 ID 不可被篡改
- [ ] 租户间数据完全隔离
- [ ] 敏感操作记录日志
