# 用户管理功能规格 (spec.md)

> 模块：002-user | 状态：已实现 | 最后更新：2026-08-10

## 1. 模块概述

### 1.1 目的
用户管理是系统核心模块，管理系统内所有用户的创建、编辑、删除、状态控制、角色分配、密码重置等功能。

### 1.2 解决的问题
- 管理员需要一个界面来统一管理所有系统用户
- 用户信息需要与部门、角色、岗位关联
- 需要支持用户导入导出，方便批量操作

### 1.3 范围
- ✅ 用户 CRUD、状态管理、密码重置
- ✅ 用户与角色、部门、岗位关联管理
- ✅ 用户导入导出
- ✅ 个人信息修改、密码修改
- ❌ 用户注册流程（由 AuthController 处理）

## 2. 用户故事
- 作为**管理员**，我可以新增用户并分配角色，以便新员工能够登录系统
- 作为**管理员**，我可以锁定/解锁用户账号，以便控制用户访问权限
- 作为**管理员**，我可以重置用户密码，以便用户忘记密码时能恢复访问
- 作为**用户**，我可以在个人中心修改自己的基本信息和密码

## 3. 功能需求

- FR-002-001: 系统 MUST 支持分页查询用户列表，支持按用户名、手机号、状态等条件筛选
- FR-002-002: 系统 MUST 支持新增用户，必填项包括用户名、昵称、密码、部门
- FR-002-003: 系统 MUST 支持修改用户基本信息（不包括密码）
- FR-002-004: 系统 MUST 支持重置用户密码（管理员权限）
- FR-002-005: 系统 MUST 支持修改用户状态（正常/停用）
- FR-002-006: 系统 MUST 支持给用户分配角色
- FR-002-007: 系统 MUST 支持批量删除用户
- FR-002-008: 系统 MUST 支持导出用户列表为 Excel
- FR-002-009: 系统 MUST 支持从 Excel 导入用户数据
- FR-002-010: 系统 MUST 在用户连续 5 次密码错误后锁定账号 10 分钟
- FR-002-011: 系统 MUST 支持管理员解锁被锁定的用户

## 4. 关键实体

| 实体 | 说明 | 关键属性 |
|------|------|----------|
| SysUser | 用户主表 | userId, userName, nickName, deptId, password, status |
| SysUserRole | 用户-角色关联 | userId, roleId |
| SysUserPost | 用户-岗位关联 | userId, postId |

## 5. 验收场景

### 场景：新增用户
- Given 管理员登录系统
- When 填写用户名、昵称、密码、选择部门 → 提交
- Then 用户创建成功，列表中出现新用户，新用户可用该账号登录

### 场景：用户被锁定
- Given 用户连续输入 5 次错误密码
- When 第 6 次尝试登录
- Then 系统提示"账号已锁定，请 10 分钟后重试"

### 场景：重置密码
- Given 管理员选中某用户
- When 点击重置密码 → 输入新密码 → 确认
- Then 用户密码更新，用户可用新密码登录

## 6. 非功能需求
- 密码 MUST 使用 BCrypt 加密存储
- 用户导入支持大数据量（流式读取 Excel）
- 用户头像 MUST 通过 OSS 对象存储管理

## 7. 依赖
- SysDept（部门管理）- 用户关联部门
- SysRole（角色管理）- 用户关联角色
- SysPost（岗位管理）- 用户关联岗位
- SysOss（对象存储）- 用户头像存储
