## 一、角色管理页面

### 1.1 角色列表页

**页面路径：** `/system/role`  
**页面标题：** 角色管理  
**权限标识：** `system:role:list`

**功能列表：**

| 功能 | 说明 | 权限标识 |
|------|------|---------|
| 搜索 | 按条件筛选角色 | system:role:list |
| 新增 | 打开新增角色弹窗 | system:role:add |
| 编辑 | 打开编辑角色弹窗 | system:role:edit |
| 删除 | 删除选中角色 | system:role:remove |
| 状态切换 | 快速切换角色状态 | system:role:edit |

**操作列按钮：**

| 按钮 | 权限标识 | 说明 |
|------|---------|------|
| 编辑 | system:role:edit | 打开编辑弹窗 |
| 删除 | system:role:remove | 确认后删除 |
| 数据权限 | system:role:edit | 打开数据权限弹窗 |
| 分配用户 | system:role:edit | 打开分配用户弹窗 |

---

### 1.2 新增/编辑角色弹窗

**表单字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 角色名称 | 输入框 | 是 | 30 字符内 |
| 权限字符 | 输入框 | 是 | 100 字符内，唯一 |
| 显示顺序 | 数字输入框 | 是 | 数字越大越靠后 |
| 状态 | 单选框 | 否 | 0-正常/1-停用 |
| 菜单权限 | 树形选择器 | 否 | 选择菜单 |
| 数据范围 | 下拉选择 | 否 | 1-全部 2-自定义 3-本部门 4-本部门及以下 5-仅本人 |
| 备注 | 文本域 | 否 | 500 字符内 |

---

### 1.3 数据权限弹窗

**表单字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 数据范围 | 下拉选择 | 是 | 选择数据范围类型 |
| 部门权限 | 树形选择器 | 条件 | 数据范围为自定义时必选 |
