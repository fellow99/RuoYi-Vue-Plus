# 003-角色管理 - 功能规格

**模块编号：** 003  
**模块名称：** 角色管理 (Role Management)  
**所属模块：** 系统管理  
**版本：** 5.X (RuoYi-Vue-Plus)  
**最后更新：** 2026-03-13

---

## 一、功能概述

角色管理用于管理系统的角色和权限分配。通过角色，可以批量控制用户的菜单和操作权限，实现基于角色的访问控制（RBAC）。

### 1.1 核心功能

- **角色 CRUD**：新增、查询、修改、删除系统角色
- **权限分配**：为角色分配菜单和操作权限
- **数据权限**：配置角色的数据范围
- **用户分配**：查看和分配角色下的用户
- **多租户支持**：租户隔离的角色管理

### 1.2 业务规则

1. **角色标识唯一性**：角色标识（roleKey）在租户内必须唯一
2. **角色名称唯一性**：角色名称在租户内必须唯一
3. **超级管理员保护**：不允许删除或修改超级管理员角色（admin）
4. **数据权限控制**：角色可配置数据范围（全部/自定义/本部门/仅本人）
5. **逻辑删除**：角色删除采用逻辑删除（del_flag=1）

## 二、功能详细设计

### 2.1 角色列表查询

**查询条件：** 角色名称、角色标识、状态、时间范围

**列表字段：** 角色 ID、角色名称、角色标识、显示顺序、状态、创建时间

**权限标识：** `system:role:list`

### 2.2 新增角色

**必填字段：** 角色名称、角色标识、显示顺序

**可选字段：** 数据范围、菜单权限、状态、备注

**业务校验：** 角色名称和标识唯一性

**权限标识：** `system:role:add`

### 2.3 修改角色

**可修改字段：** 除角色标识外的所有字段

**业务校验：** 不允许修改超级管理员角色

**权限标识：** `system:role:edit`

### 2.4 删除角色

**业务规则：** 不允许删除超级管理员角色，检查角色下是否有用户

**权限标识：** `system:role:remove`

### 2.5 分配菜单权限

**功能描述：** 为角色选择可访问的菜单和操作权限

**权限标识：** `system:role:edit`

### 2.6 分配数据权限

**数据范围：**
- 全部数据权限
- 自定义数据权限
- 本部门数据权限
- 本部门及以下数据权限
- 仅本人数据权限

**权限标识：** `system:role:edit`

### 2.7 分配用户

**功能描述：** 查看角色下的用户列表，为用户分配角色

**权限标识：** `system:role:edit`

## 三、权限设计

### 3.1 权限标识清单

| 权限标识 | 权限名称 | 说明 |
|---------|---------|------|
| `system:role:list` | 角色查询 | 查询角色列表 |
| `system:role:query` | 角色详情 | 查询角色详细信息 |
| `system:role:add` | 角色新增 | 新增角色 |
| `system:role:edit` | 角色修改 | 修改角色信息、权限 |
| `system:role:remove` | 角色删除 | 删除角色 |
| `system:role:export` | 导出角色 | 导出角色数据 |
