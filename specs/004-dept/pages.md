## 一、部门管理页面

### 1.1 部门列表页

**页面路径：** `/system/dept`  
**页面标题：** 部门管理  
**权限标识：** `system:dept:list`

**页面布局：**

```
┌─────────────────────────────────────────────────────────────┐
│ 部门管理                                      [+新增部门]    │
├─────────────────────────────────────────────────────────────┤
│ 部门名称：[____]  状态：[全部▼]             [查询] [重置]   │
├─────────────────────────────────────────────────────────────┤
│ 部门名称        │ 显示顺序 │ 负责人 │ 电话      │ 状态     │
│ ▶ 总公司        │ 1        │ 张三   │ 138****   │ 正常     │
│   ▶ 研发部      │ 1        │ 李四   │ 139****   │ 正常     │
│     ▶ 前端组    │ 1        │ 王五   │ 137****   │ 正常     │
│     ▶ 后端组    │ 2        │ 赵六   │ 136****   │ 正常     │
│   ▶ 产品部      │ 2        │ ...    │ ...       │ ...      │
└─────────────────────────────────────────────────────────────┘
```

**功能列表：**

| 功能 | 说明 | 权限标识 |
|------|------|---------|
| 搜索 | 按条件筛选部门 | system:dept:list |
| 新增 | 打开新增部门弹窗 | system:dept:add |
| 编辑 | 打开编辑部门弹窗 | system:dept:edit |
| 删除 | 删除选中部门 | system:dept:remove |
| 状态切换 | 快速切换部门状态 | system:dept:edit |

**操作列按钮：**

| 按钮 | 权限标识 | 说明 |
|------|---------|------|
| 新增 | system:dept:add | 在当前部门下新增子部门 |
| 编辑 | system:dept:edit | 打开编辑弹窗 |
| 删除 | system:dept:remove | 确认后删除 |

---

### 1.2 新增/编辑部门弹窗

**表单字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 上级部门 | 树形选择器 | 是 | 选择父部门 |
| 部门名称 | 输入框 | 是 | 30 字符内 |
| 显示顺序 | 数字输入框 | 是 | 数字越大越靠后 |
| 负责人 | 用户选择器 | 否 | 选择用户 |
| 联系电话 | 输入框 | 否 | 11 位手机号 |
| 邮箱 | 输入框 | 否 | 50 字符内 |
| 状态 | 单选框 | 否 | 0-正常/1-停用 |
