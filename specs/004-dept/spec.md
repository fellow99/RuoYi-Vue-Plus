# 004-部门管理 - 功能规格

**模块编号：** 004  
**模块名称：** 部门管理 (Department Management)  
**所属模块：** 系统管理  
**版本：** 5.X (RuoYi-Vue-Plus)  
**最后更新：** 2026-03-13

---

## 一、功能概述

部门管理用于管理系统的组织架构，支持树形部门结构，为人员和数据权限提供组织基础。

### 1.1 核心功能

- **部门 CRUD**：新增、查询、修改、删除部门
- **树形结构**：支持多级部门，父子关系
- **负责人管理**：设置部门负责人
- **状态控制**：启用/停用部门

### 1.2 业务规则

1. **部门名称唯一性**：同一父部门下部门名称唯一
2. **显示顺序**：控制同级部门的显示顺序
3. **层级限制**：建议不超过 5 级
4. **删除校验**：部门下存在子部门或用户时不能删除
5. **逻辑删除**：部门删除采用逻辑删除

---

## 二、功能详细设计

### 2.1 部门列表查询

**功能描述：** 以树形结构展示所有部门

**列表字段：** 部门名称、显示顺序、负责人、电话、状态、创建时间

**权限标识：** `system:dept:list`

### 2.2 新增部门

**必填字段：** 上级部门、部门名称、显示顺序

**可选字段：** 负责人、联系电话、邮箱、备注

**业务校验：** 同一父部门下名称唯一

**权限标识：** `system:dept:add`

### 2.3 修改部门

**可修改字段：** 除部门 ID 外的所有字段

**业务校验：** 不允许修改为自身的子部门（循环引用）

**权限标识：** `system:dept:edit`

### 2.4 删除部门

**业务规则：** 部门下存在子部门或用户时不能删除

**权限标识：** `system:dept:remove`

### 2.5 状态修改

**状态值：** `0` - 正常，`1` - 停用

**业务规则：** 停用部门后，该部门及子部门下用户不可见

**权限标识：** `system:dept:edit`

## 三、权限设计

### 3.1 权限标识清单

| 权限标识 | 权限名称 | 说明 |
|---------|---------|------|
| `system:dept:list` | 部门查询 | 查询部门列表 |
| `system:dept:query` | 部门详情 | 查询部门详细信息 |
| `system:dept:add` | 部门新增 | 新增部门 |
| `system:dept:edit` | 部门修改 | 修改部门信息 |
| `system:dept:remove` | 部门删除 | 删除部门 |
| `system:dept:export` | 导出部门 | 导出部门数据 |
