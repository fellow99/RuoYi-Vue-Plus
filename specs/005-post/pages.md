## 一、岗位管理页面

### 1.1 岗位列表页

**页面路径：** `/system/post`  
**页面标题：** 岗位管理  
**权限标识：** `system:post:list`

**页面布局：**

```
┌─────────────────────────────────────────────────────────────┐
│ 岗位管理                                      [+新增岗位]    │
├─────────────────────────────────────────────────────────────┤
│ 搜索条件：                                                   │
│  岗位编码：[____]  岗位名称：[____]  状态：[全部▼]          │
│                                              [查询] [重置]   │
├─────────────────────────────────────────────────────────────┤
│  [+批量删除] [导出]                                          │
├─────────────────────────────────────────────────────────────┤
│  岗位 ID  │ 岗位编码 │ 岗位名称    │ 显示顺序 │ 状态  │

```

**功能列表：**

| 功能 | 说明 | 权限标识 |
|------|------|---------|
| 搜索 | 按条件筛选岗位 | system:post:list |
| 新增 | 打开新增岗位弹窗 | system:post:add |
| 编辑 | 打开编辑岗位弹窗 | system:post:edit |
| 删除 | 删除选中岗位 | system:post:remove |
| 批量删除 | 批量删除岗位 | system:post:remove |
| 导出 | 导出 Excel | system:post:export |
| 状态切换 | 快速切换岗位状态 | system:post:edit |

**操作列按钮：**

| 按钮 | 权限标识 | 说明 |
|------|---------|------|
| 编辑 | system:post:edit | 打开编辑弹窗 |
| 删除 | system:post:remove | 确认后删除 |

---

### 1.2 新增/编辑岗位弹窗

**表单字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 岗位编码 | 输入框 | 是 | 64 字符内，唯一 |
| 岗位名称 | 输入框 | 是 | 50 字符内，唯一 |
| 显示顺序 | 数字输入框 | 是 | 数字越大越靠后 |
| 状态 | 单选框 | 否 | 0-正常/1-停用 |
| 备注 | 文本域 | 否 | 500 字符内 |
