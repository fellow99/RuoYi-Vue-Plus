# 005-岗位管理 - 功能规格

**模块编号：** 005  
**模块名称：** 岗位管理 (Post Management)  
**所属模块：** 系统管理  
**版本：** 5.X (RuoYi-Vue-Plus)  
**最后更新：** 2026-03-13

---

## 一、功能概述

岗位管理用于管理系统的岗位信息，岗位是用户的工作职位，与角色不同，岗位更侧重于组织架构中的职位分类。

### 1.1 核心功能

- **岗位 CRUD**：新增、查询、修改、删除岗位
- **用户关联**：查看和分配岗位下的用户
- **状态控制**：启用/停用岗位

### 1.2 业务规则

1. **岗位编码唯一性**：岗位编码（postCode）在全系统必须唯一
2. **岗位名称唯一性**：岗位名称在全系统必须唯一
3. **逻辑删除**：岗位删除采用逻辑删除
4. **删除校验**：岗位已被用户使用时不能删除

---

## 二、功能详细设计

### 2.1 岗位列表查询

**查询条件：** 岗位编码、岗位名称、状态

**列表字段：** 岗位 ID、岗位编码、岗位名称、显示顺序、状态、创建时间

**权限标识：** `system:post:list`

### 2.2 新增岗位

**必填字段：** 岗位编码、岗位名称、显示顺序

**可选字段：** 状态、备注

**业务校验：** 岗位编码和名称唯一性

**权限标识：** `system:post:add`

### 2.3 修改岗位

**可修改字段：** 除岗位 ID 外的所有字段

**权限标识：** `system:post:edit`

### 2.4 删除岗位

**业务规则：** 岗位已被用户使用时不能删除

**权限标识：** `system:post:remove`

### 2.5 状态修改

**状态值：** `0` - 正常，`1` - 停用

**权限标识：** `system:post:edit`

## 三、权限设计

### 3.1 权限标识清单

| 权限标识 | 权限名称 | 说明 |
|---------|---------|------|
| `system:post:list` | 岗位查询 | 查询岗位列表 |
| `system:post:query` | 岗位详情 | 查询岗位详细信息 |
| `system:post:add` | 岗位新增 | 新增岗位 |
| `system:post:edit` | 岗位修改 | 修改岗位信息 |
| `system:post:remove` | 岗位删除 | 删除岗位 |
| `system:post:export` | 导出岗位 | 导出岗位数据 |
