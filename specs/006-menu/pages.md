## 一、页面概述

菜单管理模块包含菜单列表、菜单新增/修改对话框、菜单树选择等页面组件。

### 1.1 页面列表

| 页面 | 路径 | 说明 |
|------|------|------|
| 菜单列表 | `/system/menu` | 菜单管理主页面 |
| 新增菜单 | 对话框 | 新增菜单表单 |
| 修改菜单 | 对话框 | 修改菜单表单 |

### 1.2 权限标识

| 页面/功能 | 权限标识 | 说明 |
|-----------|----------|------|
| 菜单列表 | `system:menu:list` | 查看菜单列表 |
| 菜单查询 | `system:menu:query` | 查询菜单详情 |
| 菜单新增 | `system:menu:add` | 新增菜单 |
| 菜单修改 | `system:menu:edit` | 修改菜单 |
| 菜单删除 | `system:menu:remove` | 删除菜单 |

### 3.2 表单字段

#### 3.2.1 上级菜单

- **类型：** 树形选择器
- **必填：** 否（默认顶级）
- **说明：** 选择父级菜单，不选表示顶级菜单
- **数据源：** 菜单树形列表

#### 3.2.2 菜单类型

- **类型：** 单选框
- **必填：** 是
- **选项：**
  - 目录（M）
  - 菜单（C）
  - 按钮（F）
- **说明：** 不同类型的菜单显示不同的配置项

#### 3.2.3 菜单名称

- **类型：** 输入框
- **必填：** 是
- **长度：** 2-50 字符
- **校验：** 同级菜单名称不能重复

#### 3.2.4 显示顺序

- **类型：** 数字输入框
- **必填：** 是
- **默认值：** 0
- **说明：** 数字越小越靠前

#### 3.2.5 路由地址

- **类型：** 输入框
- **必填：** 菜单类型必填
- **长度：** 最大 200 字符
- **说明：** 
  - 目录：配置路由路径，如 `/system`
  - 菜单：配置路由路径，如 `user`
  - 按钮：不需要配置
  - 外链：必须以 `http://` 或 `https://` 开头

#### 3.2.6 组件路径

- **类型：** 输入框
- **必填：** 菜单类型必填
- **长度：** 最大 255 字符
- **说明：**
  - 目录：通常为 `Layout`
  - 菜单：如 `system/user/index`
  - 按钮：不需要配置

#### 3.2.7 路由参数

- **类型：** 输入框
- **必填：** 否
- **长度：** 最大 255 字符
- **说明：** 路由携带的查询参数

#### 3.2.8 是否外链

- **类型：** 单选框
- **必填：** 否
- **选项：** 是 / 否
- **默认值：** 否
- **说明：** 外链地址需以 `http(s)://` 开头

#### 3.2.9 是否缓存

- **类型：** 单选框
- **必填：** 否
- **选项：** 缓存 / 不缓存
- **默认值：** 缓存
- **说明：** 使用 keep-alive 缓存页面

#### 3.2.10 显示状态

- **类型：** 单选框
- **必填：** 否
- **选项：** 显示 / 隐藏
- **默认值：** 显示
- **说明：** 隐藏后菜单不在前端显示

#### 3.2.11 菜单状态

- **类型：** 单选框
- **必填：** 否
- **选项：** 正常 / 停用
- **默认值：** 正常
- **说明：** 停用后菜单不可访问

#### 3.2.12 权限标识

- **类型：** 输入框
- **必填：** 按钮类型必填
- **长度：** 最大 100 字符
- **说明：** 用于按钮级权限控制，如 `system:user:add`

#### 3.2.13 菜单图标

- **类型：** 输入框 + 图标选择器
- **必填：** 否
- **长度：** 最大 100 字符
- **说明：** 菜单显示的图标，支持 Element Plus 图标

#### 3.2.14 备注

- **类型：** 文本域
- **必填：** 否
- **长度：** 最大 500 字符
- **说明：** 备注信息

### 3.3 表单联动

#### 3.3.1 菜单类型联动

| 菜单类型 | 显示字段 |
|----------|----------|
| 目录 | 上级菜单、菜单名称、显示顺序、路由地址、组件路径、是否外链、显示状态、菜单状态、菜单图标、备注 |
| 菜单 | 上级菜单、菜单名称、显示顺序、路由地址、组件路径、路由参数、是否外链、是否缓存、显示状态、菜单状态、权限标识、菜单图标、备注 |
| 按钮 | 上级菜单、菜单名称、显示顺序、权限标识、备注 |

#### 3.3.2 外链联动

- 选择"是外链"时，路由地址必须以 `http://` 或 `https://` 开头
- 否则提示错误

### 3.5 提交处理

#### 3.5.1 新增提交

1. 校验表单数据
2. 调用新增接口
3. 成功后刷新列表
4. 关闭对话框

#### 3.5.2 修改提交

1. 校验表单数据
2. 调用修改接口
3. 成功后刷新列表
4. 关闭对话框

#### 3.5.3 错误处理

- 菜单名称重复：提示"菜单名称已存在"
- 路由地址重复：提示"路由名称或地址已存在"
- 外链格式错误：提示"地址必须以 http(s)://开头"
- 上级菜单选择自己：提示"上级菜单不能选择自己"

## 八、接口调用

### 8.1 获取菜单列表

```javascript
const getList = async () => {
  listState.loading = true
  try {
    const res = await getMenuList(listState.queryParams)
    listState.menus = res.data
  } finally {
    listState.loading = false
  }
}
```

### 8.2 获取菜单树

```javascript
const getTreeselect = async () => {
  const res = await getMenuTreeselect()
  menuTreeOptions.value = res.data
}
```

### 8.3 新增菜单

```javascript
const handleSubmit = async () => {
  if (!formState.formRef.validate()) return
  
  formState.loading = true
  try {
    if (formState.form.menuId) {
      await updateMenu(formState.form)
      ElMessage.success('修改成功')
    } else {
      await addMenu(formState.form)
      ElMessage.success('新增成功')
    }
    getList()
    formState.visible = false
  } finally {
    formState.loading = false
  }
}
```
