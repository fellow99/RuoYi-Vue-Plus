# 006-菜单管理 - 功能规格

**模块编号：** 006  
**模块名称：** 菜单管理 (Menu Management)  
**所属模块：** 系统管理  
**版本：** 5.X (RuoYi-Vue-Plus)  
**最后更新：** 2026-03-13

---

## 一、功能概述

菜单管理是 RuoYi-Vue-Plus 的核心权限控制模块，为系统提供完整的菜单、路由和权限标识管理能力。通过该模块，系统管理员可以配置系统菜单结构、分配角色菜单权限、管理按钮级权限标识，实现细粒度的访问控制。

### 1.1 核心功能

- **菜单 CRUD**：新增、查询、修改、删除系统菜单
- **菜单类型**：支持目录（M）、菜单（C）、按钮（F）三种类型
- **路由配置**：配置菜单路由地址、组件路径、路由参数
- **权限标识**：为菜单和按钮配置权限字符串，实现按钮级权限控制
- **角色菜单分配**：为角色分配可访问的菜单权限
- **租户套餐菜单**：为租户套餐配置可用菜单
- **动态路由**：根据用户角色动态生成可访问的路由菜单
- **外链支持**：支持配置内链和外链跳转

### 1.2 与 RuoYi-Vue 的主要差异

| 特性 | RuoYi-Vue | RuoYi-Vue-Plus | 说明 |
|------|-----------|----------------|------|
| **多租户** | 不支持 | 支持 | 菜单支持租户隔离 |
| **套餐菜单** | 无 | 支持 | 租户套餐可配置菜单权限 |
| **批量删除** | 不支持 | 支持 | 支持批量级联删除菜单 |
| **权限模型** | 基础 | 增强 | 基于 Sa-Token 的权限控制 |

### 1.3 业务规则

1. **菜单名称唯一性**：同级菜单名称必须唯一
2. **路由地址唯一性**：路由名称和路由地址在全系统必须唯一
3. **外链格式校验**：外链地址必须以 http(s)://开头
4. **上级菜单校验**：上级菜单不能选择自己
5. **子菜单保护**：存在子菜单的菜单不允许删除
6. **角色分配保护**：已分配给角色的菜单不允许删除
7. **租户管理菜单保护**：租户管理菜单（ID=6）对租户套餐不可见

## 二、功能详细设计

### 2.1 菜单列表查询

**功能描述：** 查询系统菜单列表，支持多条件筛选

**查询条件：**
- 菜单名称（模糊匹配）
- 菜单状态（0 正常 / 1 停用）
- 菜单类型（M 目录 / C 菜单 / F 按钮）

**列表字段：**
- 菜单 ID、菜单名称、父菜单名称
- 菜单类型、路由地址、组件路径
- 权限标识、显示顺序、显示状态、菜单状态
- 创建时间、操作列

**权限标识：** `system:menu:list`

**API 接口：** `GET /system/menu/list`

### 2.2 新增菜单

**功能描述：** 创建新的系统菜单

**必填字段：**
- 菜单名称（2-50 字符）
- 菜单类型（M 目录 / C 菜单 / F 按钮）
- 显示顺序

**可选字段：**
- 父菜单 ID（默认顶级）
- 路由地址
- 组件路径
- 路由参数
- 是否外链（0 是 / 1 否）
- 是否缓存（0 缓存 / 1 不缓存）
- 显示状态（0 显示 / 1 隐藏）
- 菜单状态（0 正常 / 1 停用）
- 权限标识
- 菜单图标
- 备注

**业务校验：**
1. 校验菜单名称是否已存在（同级）
2. 校验路由名称或地址是否已存在
3. 外链地址必须以 http(s)://开头
4. 上级菜单不能选择自己

**权限标识：** `system:menu:add`

**API 接口：** `POST /system/menu`

### 2.3 修改菜单

**功能描述：** 修改系统菜单信息

**必填字段：**
- 菜单 ID
- 菜单名称
- 菜单类型
- 显示顺序

**可选字段：** 同新增菜单

**业务校验：**
1. 校验菜单名称是否已存在（同级，排除自身）
2. 校验路由名称或地址是否已存在（排除自身）
3. 外链地址必须以 http(s)://开头
4. 上级菜单不能选择自己

**权限标识：** `system:menu:edit`

**API 接口：** `PUT /system/menu`

### 2.4 删除菜单

**功能描述：** 删除系统菜单

**删除条件：**
- 菜单 ID（单个删除）
- 菜单 ID 列表（批量级联删除）

**业务校验：**
1. 检查是否存在子菜单，存在则不允许删除
2. 检查菜单是否已分配给角色，已分配则不允许删除

**权限标识：** `system:menu:remove`

**API 接口：** 
- `DELETE /system/menu/{menuId}`（单个删除）
- `DELETE /system/menu/cascade/{menuIds}`（批量删除）

### 2.5 获取路由信息

**功能描述：** 根据当前用户角色获取可访问的路由菜单

**返回内容：**
- 路由名称
- 路由地址
- 组件路径
- 菜单图标
- 重定向地址
- 子路由列表

**权限标识：** 登录用户

**API 接口：** `GET /system/menu/getRouters`

### 2.6 获取菜单下拉树

**功能描述：** 获取菜单树形结构，用于菜单选择

**返回内容：**
- 树形结构的菜单列表
- 每个节点包含：ID、标签、子节点

**权限标识：** `system:menu:query`

**API 接口：** `GET /system/menu/treeselect`

### 2.7 获取角色菜单树

**功能描述：** 获取角色已分配的菜单和菜单树

**返回内容：**
- 已选中的菜单 ID 列表
- 完整的菜单树形结构

**权限标识：** `system:menu:query`

**API 接口：** `GET /system/menu/roleMenuTreeselect/{roleId}`

### 2.8 获取套餐菜单树

**功能描述：** 获取租户套餐已分配的菜单和菜单树

**返回内容：**
- 已选中的菜单 ID 列表
- 完整的菜单树形结构（排除租户管理菜单）

**权限标识：** `system:menu:query` + 超级管理员角色

**API 接口：** `GET /system/menu/tenantPackageMenuTreeselect/{packageId}`

## 三、菜单类型说明

### 3.1 目录（M）

- **用途：** 用于组织菜单结构，作为菜单的父级容器
- **特点：** 不可点击，仅用于展开/收起子菜单
- **路由：** 可配置路由地址，用于一级目录的路由
- **组件：** 通常使用 Layout 布局组件

### 3.2 菜单（C）

- **用途：** 实际可访问的功能页面
- **特点：** 可点击，点击后跳转到对应页面
- **路由：** 必须配置路由地址
- **组件：** 配置具体的页面组件路径

### 3.3 按钮（F）

- **用途：** 页面内的操作按钮权限控制
- **特点：** 不显示在菜单中，仅用于权限标识
- **路由：** 不需要配置
- **组件：** 不需要配置
- **权限标识：** 必须配置，用于按钮级权限控制

## 四、路由规则

### 4.1 路由地址规则

1. **一级目录：** 以 `/` 开头，如 `/system`
2. **二级菜单：** 直接填写路径，如 `user`
3. **外链地址：** 必须以 `http://` 或 `https://` 开头
4. **内链地址：** 使用 `::` 前缀，如 `::http://example.com`

### 4.2 组件路径规则

1. **顶级目录：** 使用 `Layout` 布局组件
2. **一级菜单：** 使用完整组件路径，如 `system/user/index`
3. **内链组件：** 使用 `InnerLink` 组件
4. **父级视图：** 使用 `ParentView` 组件

### 4.3 特殊路由处理

| 场景 | 路由地址 | 组件 | 说明 |
|------|----------|------|------|
| 一级目录 | `/system` | Layout | 使用 Layout 布局 |
| 一级菜单（内嵌） | `user` | system/user/index | 默认内嵌在 Layout 中 |
| 一级菜单（独立） | `/system/user` | system/user/index | 独立页面，需配置完整路由 |
| 外链 | `https://example.com` | - | 新窗口打开外链 |
| 内链 | `::http://example.com` | InnerLink | 在当前窗口打开外链 |

## 五、权限控制

### 5.1 权限标识格式

权限标识采用 `模块：功能：操作` 的格式，例如：

- `system:menu:list` - 菜单列表查询
- `system:menu:add` - 菜单新增
- `system:menu:edit` - 菜单修改
- `system:menu:remove` - 菜单删除
- `system:menu:query` - 菜单详情查询

### 5.2 按钮级权限控制

在 Vue 前端使用 `v-hasPermi` 指令控制按钮显示：

```vue
<el-button v-hasPermi="system:menu:add">新增</el-button>
<el-button v-hasPermi="system:menu:edit">修改</el-button>
<el-button v-hasPermi="system:menu:remove">删除</el-button>
```

### 5.3 角色菜单权限

- 角色可分配多个菜单权限
- 用户继承所属角色的所有菜单权限
- 菜单权限包含：页面访问权限、按钮操作权限

## 六、多租户支持

### 6.1 租户菜单隔离

- 每个租户拥有独立的菜单配置
- 租户管理员只能管理本租户的菜单
- 超级管理员可管理所有租户的菜单

### 6.2 租户套餐菜单

- 租户套餐可配置可用的菜单列表
- 租户创建时自动分配套餐菜单
- 租户只能访问套餐内的菜单

### 6.3 特殊菜单处理

- 租户管理菜单（ID=6）对租户套餐不可见
- 仅超级管理员可访问租户管理相关菜单

## 七、状态说明

### 7.1 显示状态

| 值 | 状态 | 说明 |
|----|------|------|
| 0 | 显示 | 菜单在前端显示 |
| 1 | 隐藏 | 菜单在前端隐藏 |

### 7.2 菜单状态

| 值 | 状态 | 说明 |
|----|------|------|
| 0 | 正常 | 菜单可正常使用 |
| 1 | 停用 | 菜单不可使用 |

### 7.3 是否外链

| 值 | 状态 | 说明 |
|----|------|------|
| 0 | 是 | 外链地址，新窗口打开 |
| 1 | 否 | 内部路由 |

### 7.4 是否缓存

| 值 | 状态 | 说明 |
|----|------|------|
| 0 | 缓存 | 页面使用 keep-alive 缓存 |
| 1 | 不缓存 | 页面不缓存 |
