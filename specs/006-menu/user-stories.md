# 006-菜单管理 - 用户故事

**模块编号：** 006  
**模块名称：** 菜单管理  
**版本：** 5.X (RuoYi-Vue-Plus)  
**最后更新：** 2026-03-13

---

## 一、用户角色

### 1.1 超级管理员

- **描述：** 系统最高权限管理员
- **权限：** 完整的菜单管理权限
- **场景：** 配置系统菜单结构、分配角色菜单权限

### 1.2 租户管理员

- **描述：** 租户内部的管理员
- **权限：** 有限的菜单管理权限（租户内）
- **场景：** 查看租户菜单、申请菜单权限

---

## 二、用户故事

### 2.1 菜单配置

#### US-001：新增一级目录

**作为** 超级管理员  
**我想** 新增一个一级目录  
**以便** 组织相关的功能菜单

**验收标准：**
- [ ] 可以设置目录名称、显示顺序、图标
- [ ] 可以配置路由地址（如 `/system`）
- [ ] 目录名称在同级中必须唯一
- [ ] 新增成功后在菜单列表中显示

**测试场景：**
```
Given 我处于菜单管理页面
When 我点击"新增"按钮
And 选择菜单类型为"目录"
And 填写菜单名称为"营销中心"
And 填写路由地址为"/marketing"
And 点击"确定"
Then 提示"新增成功"
And 菜单列表中出现"营销中心"目录
```

---

#### US-002：新增功能菜单

**作为** 超级管理员  
**我想** 在目录下新增功能菜单  
**以便** 用户可以访问具体功能页面

**验收标准：**
- [ ] 可以选择上级目录
- [ ] 可以配置路由地址和组件路径
- [ ] 可以设置权限标识
- [ ] 可以配置是否缓存页面
- [ ] 路由地址必须唯一

**测试场景：**
```
Given 我已创建"营销中心"目录
When 我点击"新增"按钮
And 选择上级菜单为"营销中心"
And 选择菜单类型为"菜单"
And 填写菜单名称为"活动管理"
And 填写路由地址为"activity"
And 填写组件路径为"marketing/activity/index"
And 填写权限标识为"marketing:activity:list"
And 点击"确定"
Then 提示"新增成功"
And "营销中心"目录下出现"活动管理"菜单
```

---

#### US-005：删除菜单

**作为** 超级管理员  
**我想** 删除不需要的菜单  
**以便** 保持菜单结构的整洁

And 确认删除操作

And 菜单从列表中消失
```

```
Given 我尝试删除一个有子菜单的菜单
When 我点击"删除"按钮
Then 提示"存在子菜单，不允许删除"
And 菜单未被删除
```

```
Given 我尝试删除一个已分配给角色的菜单
