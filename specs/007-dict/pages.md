# 007-字典管理 - 页面设计

**模块编号：** 007  
**模块名称：** 字典管理  
**版本：** 5.X (RuoYi-Vue-Plus)  
**最后更新：** 2026-03-13

---

## 一、页面概述

字典管理模块包含字典类型列表、字典数据列表、新增/修改对话框等页面。

### 1.1 页面列表

| 页面 | 路径 | 说明 |
|------|------|------|
| 字典类型列表 | `/system/dict/type` | 字典类型管理主页面 |
| 字典数据列表 | `/system/dict/data` | 字典数据管理页面 |
| 新增/修改对话框 | 对话框 | 表单对话框 |

---

## 二、字典类型列表页

### 2.1 页面布局

```
+----------------------------------------------------------+
|  [搜索条件]                                               |
|  字典名称：[____]  字典类型：[____]  状态：[全部▼]       |
|  [🔍 搜索] [🔄 重置]                                      |
+----------------------------------------------------------+
|  [+ 新增] [📤 导出] [🗑️ 删除] [🔄 刷新缓存]              |
+----------------------------------------------------------+
|  [字典类型表格]                                           |
|  -------------------------------------------------------- |
|  | 选择 | 字典 ID | 字典名称 | 字典类型 | 状态 | 操作 | |
|  |------|---------|----------|----------|------|------| |
|  | ☐    | 1       | 用户性别 | sys_user_sex | 正常 | [修改]| |
|  -------------------------------------------------------- |
+----------------------------------------------------------+
```

### 2.2 列表字段

| 字段 | 说明 | 宽度 |
|------|------|------|
| 选择 | 复选框（批量删除） | 50px |
| 字典 ID | 字典主键 | 80px |
| 字典名称 | 字典显示名称 | 150px |
| 字典类型 | 字典类型标识 | 150px |
| 状态 | 正常/停用 | 80px |
| 备注 | 备注信息 | 自适应 |
| 创建时间 | 创建时间 | 160px |
| 操作 | 修改/删除/数据按钮 | 200px |

### 2.3 操作按钮

| 按钮 | 权限 | 说明 |
|------|------|------|
| 新增 | `system:dict:add` | 打开新增对话框 |
| 导出 | `system:dict:export` | 导出为 Excel |
| 删除 | `system:dict:remove` | 批量删除 |
| 刷新缓存 | `system:dict:remove` | 刷新字典缓存 |
| 数据 | `system:dict:list` | 查看字典数据 |

## 四、新增/修改对话框

### 4.1 字典类型表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 字典名称 | 输入框 | 是 | 2-100 字符 |
| 字典类型 | 输入框 | 是 | 2-100 字符，唯一 |
| 状态 | 单选框 | 否 | 正常/停用 |
| 备注 | 文本域 | 否 | 最大 500 字符 |

### 4.2 字典数据表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 字典标签 | 输入框 | 是 | 1-100 字符 |
| 字典键值 | 输入框 | 是 | 1-100 字符 |
| 字典排序 | 数字框 | 是 | 默认 0 |
| 样式属性 | 输入框 | 否 | CSS 类名 |
| 表格样式 | 输入框 | 否 | 表格样式 |
| 是否默认 | 单选框 | 否 | Y/N |
| 状态 | 单选框 | 否 | 正常/停用 |
| 备注 | 文本域 | 否 | 最大 500 字符 |
