# 007-字典管理 - 功能规格

**模块编号：** 007  
**模块名称：** 字典管理 (Dict Management)  
**所属模块：** 系统管理  
**版本：** 5.X (RuoYi-Vue-Plus)  
**最后更新：** 2026-03-13

---

## 一、功能概述

字典管理是 RuoYi-Vue-Plus 的基础数据管理模块，为系统提供统一的字典类型和字典数据管理能力。通过该模块，系统管理员可以维护系统中的下拉选项、状态标识等基础数据，实现数据标准化和统一管理。

### 1.1 核心功能

- **字典类型管理**：新增、查询、修改、删除字典类型
- **字典数据管理**：新增、查询、修改、删除字典数据
- **字典缓存**：字典数据缓存和刷新
- **字典导出**：导出字典类型为 Excel
- **租户隔离**：支持多租户字典数据隔离

### 1.2 与 RuoYi-Vue 的主要差异

| 特性 | RuoYi-Vue | RuoYi-Vue-Plus | 说明 |
|------|-----------|----------------|------|
| **多租户** | 不支持 | 支持 | 字典支持租户隔离 |
| **缓存刷新** | 支持 | 增强 | 基于 Lock4j 的分布式锁 |
| **数据校验** | 基础 | 增强 | 更严格的唯一性校验 |

### 1.3 业务规则

1. **字典类型唯一性**：字典类型（dictType）在全系统必须唯一
2. **字典数据唯一性**：同一类型下的字典键值（dictValue）必须唯一
3. **内置字典保护**：系统内置字典不允许删除
4. **缓存同步**：字典修改后自动刷新缓存

## 二、功能详细设计

### 2.1 字典类型列表

**功能描述：** 分页查询字典类型列表

**查询条件：**
- 字典名称（模糊匹配）
- 字典类型（模糊匹配）
- 状态（0 正常 / 1 停用）

**列表字段：**
- 字典 ID、字典名称、字典类型
- 状态、备注、创建时间、操作列

**权限标识：** `system:dict:list`

**API 接口：** `GET /system/dict/type/list`

### 2.2 新增字典类型

**功能描述：** 创建新的字典类型

**必填字段：**
- 字典名称（2-30 字符）
- 字典类型（2-30 字符，唯一）

**可选字段：**
- 状态（0 正常 / 1 停用）
- 备注

**业务校验：**
1. 校验字典类型是否已存在

**权限标识：** `system:dict:add`

**API 接口：** `POST /system/dict/type`

### 2.3 修改字典类型

**功能描述：** 修改字典类型信息

**必填字段：**
- 字典 ID
- 字典名称
- 字典类型

**业务校验：**
1. 校验字典类型是否已存在（排除自身）

**权限标识：** `system:dict:edit`

**API 接口：** `PUT /system/dict/type`

### 2.4 删除字典类型

**功能描述：** 删除字典类型及关联数据

**删除条件：**
- 字典 ID 列表

**业务校验：**
1. 检查是否存在关联的字典数据

**权限标识：** `system:dict:remove`

**API 接口：** `DELETE /system/dict/type/{dictIds}`

### 2.5 刷新字典缓存

**功能描述：** 刷新系统字典缓存

**权限标识：** `system:dict:remove`

**API 接口：** `DELETE /system/dict/type/refreshCache`

### 2.6 字典数据列表

**功能描述：** 分页查询字典数据列表

**查询条件：**
- 字典类型
- 字典标签（模糊匹配）
- 状态

**列表字段：**
- 字典编码、字典标签、字典键值
- 字典排序、样式属性、表格样式
- 是否默认、状态、备注

**权限标识：** `system:dict:list`

**API 接口：** `GET /system/dict/data/list`

### 2.7 根据类型查询字典数据

**功能描述：** 根据字典类型查询所有字典数据

**返回内容：** 该类型下的所有字典数据列表

**权限标识：** 无（公开接口）

**API 接口：** `GET /system/dict/data/type/{dictType}`

## 三、字典类型说明

### 3.1 系统内置字典

| 字典类型 | 字典名称 | 说明 |
|----------|----------|------|
| sys_normal_disable | 系统开关 | 正常/停用 |
| sys_yes_no | 系统是否 | 是/否 |
| sys_user_sex | 用户性别 | 男/女/未知 |
| sys_show_hide | 显示隐藏 | 显示/隐藏 |

### 3.2 字典数据属性

| 属性 | 说明 | 用途 |
|------|------|------|
| dictLabel | 字典标签 | 前端显示文本 |
| dictValue | 字典键值 | 后端存储值 |
| cssClass | 样式属性 | 前端样式扩展 |
| listClass | 表格样式 | 表格列样式 |
| isDefault | 是否默认 | 默认选中项 |

## 四、缓存机制

### 4.1 缓存键

- 字典类型缓存：`dict_type:{dictType}`
- 字典数据缓存：`dict_data:{dictType}`

### 4.2 缓存刷新

- 新增/修改/删除字典类型时刷新缓存
- 新增/修改/删除字典数据时刷新缓存
- 手动刷新缓存接口

---

## 五、多租户支持

### 5.1 租户字典隔离

- 每个租户拥有独立的字典数据
- 系统内置字典所有租户共享
- 租户可自定义扩展字典

### 5.2 字典同步

- 超级管理员可同步字典到所有租户
- 租户字典修改不影响其他租户
