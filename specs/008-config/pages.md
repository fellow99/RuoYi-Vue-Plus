## 二、表单字段

### 新增/修改对话框

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 参数名称 | 输入框 | 是 | 最大 100 字符 |
| 参数键名 | 输入框 | 是 | 最大 100 字符，唯一 |
| 参数键值 | 输入框/文本域 | 是 | 最大 500 字符 |
| 系统内置 | 单选框 | 否 | Y/N |
| 备注 | 文本域 | 否 | 最大 500 字符 |
