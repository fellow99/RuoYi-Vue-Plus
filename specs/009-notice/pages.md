## 二、表单字段

### 新增/修改对话框

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 公告标题 | 输入框 | 是 | 最大 50 字符 |
| 公告类型 | 单选框 | 是 | 通知/公告 |
| 公告内容 | 富文本编辑器 | 是 | 支持 HTML |
| 状态 | 单选框 | 否 | 正常/关闭 |
| 备注 | 文本域 | 否 | 最大 500 字符 |
