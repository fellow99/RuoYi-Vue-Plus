## 一、页面布局

```
+----------------------------------------------------------+
|  [搜索条件]                                               |
|  操作模块：[____]  业务类型：[全部▼]  操作人员：[____]   |
|  状态：[全部▼]  操作时间：[开始] 至 [结束]               |
|  [🔍 搜索] [🔄 重置]                                      |
+----------------------------------------------------------+
|  [📤 导出] [🗑️ 删除] [🧹 清空日志]                      |
+----------------------------------------------------------+
|  [操作日志表格]                                           |
|  -------------------------------------------------------- |
|  | 选择 | 日志 ID | 操作模块 | 业务类型 | 操作人员 | 状态 | 操作时间 | 操作 | |
|  |------|---------|----------|----------|----------|------|----------|------| |
|  | ☐    | 1       | 用户管理 | 新增     | admin    | 正常 | 2024-01-01 | [详情]| |
|  -------------------------------------------------------- |
+----------------------------------------------------------+
```

---

## 二、详情对话框

| 字段 | 说明 |
|------|------|
| 操作模块 | 操作的模块名称 |
| 业务类型 | 新增/修改/删除等 |
| 请求方法 | 完整的 Controller 方法 |
| 请求 URL | 请求的地址 |
| 请求方式 | GET/POST/PUT/DELETE |
| 操作人员 | 操作者账号 |
| 部门名称 | 所属部门 |
| 操作地址 | IP 地址 |
| 操作地点 | 地理位置 |
| 请求参数 | 请求的参数 JSON |
| 返回参数 | 返回的结果 JSON |
| 操作状态 | 正常/异常 |
| 错误消息 | 异常时的错误信息 |
| 操作时间 | 操作发生时间 |
| 消耗时间 | 执行耗时（毫秒） |
