# 010-操作日志 - 功能规格

**模块编号：** 010  
**模块名称：** 操作日志 (Operation Log)  
**所属模块：** 系统监控  
**版本：** 5.X (RuoYi-Vue-Plus)  
**最后更新：** 2026-03-13

---

## 一、功能概述

操作日志模块记录用户在系统中的所有操作行为，包括操作模块、业务类型、请求方法、操作人员、操作时间等，支持日志查询、导出和清理。

### 1.1 核心功能

- **日志列表**：分页查询操作日志
- **多条件查询**：按模块、业务类型、操作人员、状态等查询
- **日志详情**：查看请求参数和返回参数
- **日志导出**：导出操作日志为 Excel
- **日志清理**：批量删除或清空日志
- **日志解锁**：解锁账户（关联登录日志）

### 1.2 业务规则

1. **自动记录**：通过 AOP 自动记录操作日志
2. **只读日志**：日志不允许修改
3. **批量删除**：支持批量删除日志
4. **清空日志**：支持一键清空所有日志

### 1.3 业务类型

| 类型值 | 类型名称 | 说明 |
|--------|----------|------|
| 0 | 其他 | 其他操作 |
| 1 | 新增 | 新增操作 |
| 2 | 修改 | 修改操作 |
| 3 | 删除 | 删除操作 |
| 4 | 授权 | 授权操作 |
| 5 | 导出 | 导出操作 |
| 6 | 导入 | 导入操作 |
| 7 | 强退 | 强退操作 |
| 8 | 生成代码 | 代码生成 |
| 9 | 清空数据 | 清空数据 |

## 二、功能详细设计

### 2.1 日志列表

**查询条件：** 操作模块、业务类型、操作人员、状态、操作时间

**列表字段：** 日志 ID、操作模块、业务类型、请求方法、操作人员、操作地址、操作状态、操作时间、消耗时间

**权限标识：** `monitor:operlog:list`

### 2.2 日志详情

**展示内容：** 请求 URL、请求方法、请求参数、返回参数、错误消息

**权限标识：** `monitor:operlog:list`

### 2.3 日志导出

**导出内容：** 所有列表字段

**权限标识：** `monitor:operlog:export`

### 2.4 日志删除

**删除方式：** 批量删除选中的日志

**权限标识：** `monitor:operlog:remove`

### 2.5 日志清理

**功能：** 清空所有操作日志

**权限标识：** `monitor:operlog:remove`
