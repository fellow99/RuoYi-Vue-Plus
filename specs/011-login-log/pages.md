## 二、列表字段

| 字段 | 说明 | 宽度 |
|------|------|------|
| 选择 | 复选框 | 50px |
| 日志 ID | 主键 | 80px |
| 用户名 | 用户账号 | 120px |
| 客户端 | 客户端标识 | 100px |
| 设备类型 | pc/mobile | 100px |
| 状态 | 成功/失败 | 80px |
| 登录 IP | IP 地址 | 140px |
| 登录地点 | 地理位置 | 150px |
| 浏览器 | 浏览器类型 | 120px |
| 操作系统 | 操作系统 | 100px |
| 提示消息 | 失败时的消息 | 自适应 |
| 登录时间 | 登录时间 | 160px |
| 操作 | 解锁按钮 | 80px |

## 三、解锁账户

**触发条件：** 点击"解锁"按钮

**操作：** 调用解锁接口，删除 Redis 中的密码错误计数

**提示：** "账户解锁成功"
