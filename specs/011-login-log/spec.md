# 011-登录日志 - 功能规格

**模块编号：** 011  
**模块名称：** 登录日志 (Login Log)  
**所属模块：** 系统监控  
**版本：** 5.X (RuoYi-Vue-Plus)  
**最后更新：** 2026-03-13

---

## 一、功能概述

登录日志模块记录用户的登录行为，包括登录成功和失败的记录，支持登录日志查询、导出、删除和清理，以及账户解锁功能。

### 1.1 核心功能

- **日志列表**：分页查询登录日志
- **多条件查询**：按用户名、IP 地址、状态、登录时间查询
- **日志导出**：导出登录日志为 Excel
- **日志删除**：批量删除日志
- **日志清理**：清空所有日志
- **账户解锁**：解锁因密码错误被锁定的账户

### 1.2 业务规则

1. **自动记录**：登录时自动记录日志
2. **失败锁定**：连续密码错误多次后锁定账户
3. **只读日志**：日志不允许修改
4. **批量操作**：支持批量删除和清空

### 1.3 登录状态

| 状态值 | 状态名称 | 说明 |
|--------|----------|------|
| 0 | 成功 | 登录成功 |
| 1 | 失败 | 登录失败 |

---

## 二、功能详细设计

### 2.1 日志列表

**查询条件：** 用户名、IP 地址、状态、登录时间

**列表字段：** 日志 ID、用户名、客户端、设备类型、登录状态、登录 IP、登录地点、浏览器、操作系统、提示消息、登录时间

**权限标识：** `monitor:logininfor:list`

### 2.2 日志导出

**导出内容：** 所有列表字段

**权限标识：** `monitor:logininfor:export`

### 2.3 日志删除

**删除方式：** 批量删除选中的日志

**权限标识：** `monitor:logininfor:remove`

### 2.4 日志清理

**功能：** 清空所有登录日志

**权限标识：** `monitor:logininfor:remove`

### 2.5 账户解锁

**功能：** 解锁因密码错误被锁定的账户

**权限标识：** `monitor:logininfor:unlock`

**逻辑：** 删除 Redis 中的密码错误计数缓存
