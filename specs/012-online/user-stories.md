# 012-online 用户故事文档

## 用户角色

| 角色 | 说明 |
|------|------|
| 系统管理员 | 拥有所有权限，可管理所有在线用户 |
| 普通用户 | 只能查看和管理自己的在线设备 |

---

## 用户故事

### US-001: 查看在线用户列表

**作为** 系统管理员  
**我想要** 查看所有在线用户的列表  
**以便于** 了解当前系统的用户活跃情况

**验收标准**:
- [ ] 能看到所有已登录用户的会话信息
- [ ] 能看到用户的登录时间、IP 地址、设备信息
- [ ] 列表支持分页展示
- [ ] 数据实时刷新

---

### US-002: 搜索在线用户

**作为** 系统管理员  
**我想要** 根据用户名或 IP 地址搜索在线用户  
**以便于** 快速定位特定用户

**验收标准**:
- [ ] 支持按用户名模糊搜索
- [ ] 支持按 IP 地址模糊搜索
- [ ] 支持组合搜索
- [ ] 搜索结果准确

---

### US-003: 强制踢出用户

**作为** 系统管理员  
**我想要** 强制踢出可疑或违规的在线用户  
**以便于** 保障系统安全

**验收标准**:
- [ ] 点击强退按钮后弹出确认对话框
- [ ] 确认后用户立即下线
- [ ] 操作成功显示提示信息
- [ ] 操作记录被记录到日志
- [ ] 列表自动刷新

---

### US-004: 查看自己的在线设备

**作为** 普通用户  
**我想要** 查看自己账号的所有在线设备  
**以便于** 了解账号的登录情况

**验收标准**:
- [ ] 能看到自己账号的所有在线设备
- [ ] 显示每个设备的登录时间、IP、设备类型
- [ ] 无需特殊权限即可访问

---

### US-005: 管理自己的在线设备

**作为** 普通用户  
**我想要** 强制踢出自己的其他在线设备  
**以便于** 在发现异常登录时保护账号安全

**验收标准**:
- [ ] 可以选择踢出任意一个在线设备
- [ ] 操作需要二次确认
- [ ] 踢出后立即生效
- [ ] 不能踢出当前正在使用的设备

---

## 使用场景

### 场景 1: 安全审计
管理员发现异常登录行为，通过在线用户列表查看可疑 IP，强制踢出该用户。

### 场景 2: 账号保护
用户发现自己账号在异地登录，立即登录系统踢出可疑设备。

### 场景 3: 系统维护
系统维护前，管理员批量踢出所有在线用户，确保维护期间数据一致性。

---

## 用户体验要求

1. **响应速度**: 列表加载时间 < 2 秒
2. **操作反馈**: 所有操作都有明确的提示信息
3. **确认机制**: 强退操作必须二次确认
4. **实时性**: 数据支持手动刷新
