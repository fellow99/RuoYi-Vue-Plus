## 页面设计：定时任务列表

### 页面布局

```
┌─────────────────────────────────────────────────────────────────┐
│  定时任务                                                        │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 任务名称：[____] 任务分组：[____] 状态：[▼]  [搜索][重置]│   │
│  └─────────────────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────────────────┤
│  [新增] [修改] [删除] [启动] [停止] [触发]                      │
├─────────────────────────────────────────────────────────────────┤
│  任务名│分组│Cron 表达式 │类型│状态│ 操作                        │
│  ──────┼────┼───────────┼────┼────┼──────────────────────────  │
│  test  │def │0/5*...*?  │JAVA│运行│[编辑][删除][启动][停止][触发]│
└─────────────────────────────────────────────────────────────────┘
```

### 数据表格

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 任务名称 | jobName | 120 | - |
| 任务分组 | jobGroup | 100 | - |
| Cron 表达式 | cronExpression | 150 | - |
| 任务类型 | jobType | 80 | - |
| 状态 | status | 80 | 运行/停止 |
| 操作 | - | 250 | 编辑/删除/启动/停止/触发 |

### 操作按钮

| 按钮 | 权限 | 说明 |
|------|------|------|
| 新增 | monitor:job:add | 创建新任务 |
| 编辑 | monitor:job:edit | 修改任务配置 |
| 删除 | monitor:job:delete | 删除任务 |
| 启动 | monitor:job:start | 启动任务 |
| 停止 | monitor:job:stop | 停止任务 |
| 触发 | monitor:job:list | 手动执行一次 |
