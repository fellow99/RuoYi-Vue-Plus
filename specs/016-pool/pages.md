```
┌─────────────────────────────────────────────────────────────────┐
│  连接池监控                                                      │
├─────────────────────────────────────────────────────────────────┤
│  连接池：HikariPool-1                                           │
├─────────────────────────────────────────────────────────────────┤
│  总连接数    活跃连接    空闲连接    等待连接    使用率          │
│  ┌───────┐  ┌───────┐  ┌───────┐  ┌───────┐  ┌───────┐       │
│  │  50   │  │  10   │  │  40   │  │  0    │  │ 20%   │       │
│  └───────┘  └───────┘  └───────┘  └───────┘  └───────┘       │
├─────────────────────────────────────────────────────────────────┤
│  连接数趋势图                                                   │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  [折线图展示连接数变化趋势]                             │   │
│  └─────────────────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────────────────┤
│  慢 SQL 统计 (TOP 10)                                           │
│  SQL 语句           │ 执行次数 │ 平均耗时 │ 最大耗时           │
│  ──────────────────┼──────────┼──────────┼──────────          │
│  SELECT * FROM...  │ 1000     │ 50ms     │ 500ms              │
└─────────────────────────────────────────────────────────────────┘
```

## 交互说明

1. 页面加载时自动获取连接池信息
2. 支持手动刷新
3. 支持定时自动刷新（默认 10 秒）
4. 慢 SQL 按平均耗时排序
