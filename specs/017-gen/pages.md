## 三、页面详细设计

### 3.1 代码生成列表页

**组件路径：** `tool/gen/index.vue`

#### 3.1.1 页面布局

```
┌────────────────────────────────────────────┐
│  搜索栏                                     │
│  ┌──────────┬──────────┬──────────┐        │
│  │数据源     │表名称     │表描述     │ 搜索  │
│  └──────────┴──────────┴──────────┘        │
├────────────────────────────────────────────┤
│  工具栏                                     │
│  [导入表] [批量生成] [刷新]                 │
├────────────────────────────────────────────┤
│  数据表格                                   │
│  ┌────┬──────┬──────┬──────┬──────┬────┐  │
│  │选择│表名  │描述  │类名  │包路径│操作│  │
│  ├────┼──────┼──────┼──────┼──────┼────┤  │
│  │ ☐  │...   │...   │...   │...   │... │  │
│  └────┴──────┴──────┴──────┴──────┴────┘  │
├────────────────────────────────────────────┤
│  分页器                                     │
└────────────────────────────────────────────┘
```

#### 3.1.2 搜索条件

| 字段 | 类型 | 说明 |
|------|------|------|
| 数据源 | Select | 下拉选择（数据源列表） |
| 表名称 | Input | 模糊匹配 |
| 表描述 | Input | 模糊匹配 |
| 创建时间 | DateRange | 时间范围选择 |

#### 3.1.3 数据表格列

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 选择 | selection | 50 | 多选框 |
| 表名称 | tableName | 120 | 数据库表名 |
| 表描述 | tableComment | 120 | 表注释 |
| 实体类 | className | 100 | 生成的类名 |
| 包路径 | packageName | 150 | 生成包路径 |
| 模块名 | moduleName | 100 | 生成模块名 |
| 创建时间 | createTime | 160 | 导入时间 |
| 操作 | - | 250 | 操作按钮组 |

#### 3.1.4 操作按钮

**行操作：**
- **编辑** - 修改代码生成配置（权限：`tool:gen:edit`）
- **预览** - 预览生成的代码（权限：`tool:gen:preview`）
- **下载** - 下载代码 ZIP（权限：`tool:gen:code`）
- **生成** - 生成到自定义路径（权限：`tool:gen:code`）
- **同步** - 同步数据库（权限：`tool:gen:edit`）
- **删除** - 删除配置（权限：`tool:gen:remove`）

**工具栏操作：**
- **导入表** - 打开导入表对话框（权限：`tool:gen:import`）
- **批量生成** - 批量下载选中表的代码（权限：`tool:gen:code`）
- **刷新** - 重新加载数据

#### 3.1.5 交互逻辑

**加载流程：**
1. 页面加载时获取数据源列表
2. 调用 `list()` API 加载代码生成列表
3. 渲染表格和分页器

**搜索流程：**
1. 用户输入搜索条件
2. 点击"搜索"按钮
3. 调用 `list()` API 带参数查询
4. 更新表格数据

**导入表流程：**
1. 点击"导入表"按钮
2. 打开导入表对话框
3. 选择数据源和表
4. 点击"确定"导入
5. 刷新列表

**编辑配置流程：**
1. 点击"编辑"按钮
2. 打开编辑对话框
3. 加载表配置和字段配置
4. 修改配置
5. 点击"确定"保存
6. 刷新列表

**预览代码流程：**
1. 点击"预览"按钮
2. 调用 `preview()` API
3. 打开预览对话框
4. 显示代码文件列表
5. 点击文件名查看内容

**下载代码流程：**
1. 点击"下载"按钮
2. 调用 `download()` API
3. 浏览器下载 ZIP 文件

**同步数据库流程：**
1. 点击"同步"按钮
2. 确认操作
3. 调用 `synchDb()` API
4. 刷新列表

**删除流程：**
1. 点击"删除"按钮（或选择多条后点击批量删除）
2. 确认删除
3. 调用 `remove()` API
4. 刷新列表

### 3.2 导入表对话框

**组件路径：** `tool/gen/importTable.vue`

#### 3.2.1 对话框布局

```
┌────────────────────────────────────┐
│  导入表结构                    [×] │
├────────────────────────────────────┤
│  数据源：[下拉选择]                │
├────────────────────────────────────┤
│  表列表：                          │
│  ┌──────────────────────────────┐  │
│  │ ☐ 表 1   │ 描述 1            │  │
│  │ ☐ 表 2   │ 描述 2            │  │
│  │ ☐ 表 3   │ 描述 3            │  │
│  │ ...                          │  │
│  └──────────────────────────────┘  │
├────────────────────────────────────┤
│          [取消]  [确定]            │
└────────────────────────────────────┘
```

#### 3.2.2 表单字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 数据源 | Select | 是 | 选择数据源 |
| 表选择 | Table | 是 | 多选表（支持搜索） |

#### 3.2.3 交互逻辑

**打开对话框：**
1. 点击"导入表"按钮
2. 调用 `getDataNames()` 获取数据源列表
3. 显示对话框

**选择数据源：**
1. 选择数据源
2. 调用 `db/list()` API 查询表列表
3. 渲染表选择表格

**选择表：**
1. 勾选要导入的表（支持多选）
2. 已导入的表显示为禁用状态

**确认导入：**
1. 点击"确定"按钮
2. 验证至少选择一个表
3. 调用 `importTable()` API
4. 关闭对话框
5. 刷新列表

**组件路径：** `tool/gen/edit.vue`

```
│  │ 模块名：[输入框]                 │  │
│  │ 业务名：[输入框]                 │  │
│  │ 功能名：[输入框]                 │  │
│  │ 作者：[输入框]                   │  │
│  │ 生成方式：○ ZIP ○ 自定义路径     │  │
│  │ 生成路径：[输入框]               │  │

│            [取消]  [确定]              │
└────────────────────────────────────────┘
```

#### 3.3.2 基本信息字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 数据源 | Input | 是 | 只读 |
| 表名称 | Input | 是 | 只读 |
| 表描述 | Input | 是 | - |
| 实体类 | Input | 是 | 首字母大写 |
| 模板类型 | Radio | 是 | crud/tree |
| 包路径 | Input | 是 | 如：org.dromara |
| 模块名 | Input | 是 | 如：system |
| 业务名 | Input | 是 | 如：user |
| 功能名 | Input | 是 | 如：用户 |
| 作者 | Input | 是 | 如：Lion Li |
| 生成方式 | Radio | 是 | 0-ZIP/1-自定义路径 |
| 生成路径 | Input | 否 | 自定义路径时填写 |

#### 3.3.3 字段配置表格

| 列名 | 编辑方式 | 说明 |
|------|---------|------|
| 列名 | Input（只读） | 数据库列名 |
| 列描述 | Input | 字段描述 |
| Java 类型 | Select | String/Long/Date 等 |
| Java 属性 | Input | 驼峰命名 |
| 主键 | Checkbox | 是否主键 |
| 自增 | Checkbox | 是否自增 |
| 必填 | Checkbox | 是否必填 |
| 插入 | Checkbox | 是否插入字段 |
| 编辑 | Checkbox | 是否编辑字段 |
| 列表 | Checkbox | 是否列表字段 |
| 查询 | Checkbox | 是否查询字段 |
| 查询方式 | Select | EQ/LIKE 等 |
| 显示类型 | Select | Input/Select 等 |
| 字典类型 | Select | 关联字典 |

#### 3.3.4 交互逻辑

**打开对话框：**
1. 点击"编辑"按钮
2. 调用 `getInfo(tableId)` API
3. 填充基本信息和字段列表
4. 显示对话框

**保存配置：**
1. 点击"确定"按钮
2. 验证必填字段
3. 调用 `edit()` API
4. 关闭对话框
5. 刷新列表

## 四、前端 API 调用

```typescript
// 查询代码生成列表
export function listGen(query: PageQuery) {
  return request({
    url: '/tool/gen/list',
    method: 'get',
    params: query
  })
}

// 查询数据库表列表
export function listDbGen(query: PageQuery) {
  return request({
    url: '/tool/gen/db/list',
    method: 'get',
    params: query
  })
}

// 获取代码生成详情
export function getGenInfo(tableId: number) {
  return request({
    url: '/tool/gen/' + tableId,
    method: 'get'
  })
}

// 导入表结构
export function importTable(data: { tables: string, dataName: string }) {
  return request({
    url: '/tool/gen/importTable',
    method: 'post',
    params: data
  })
}

// 修改代码生成配置
export function editGen(data: GenTable) {
  return request({
    url: '/tool/gen',
    method: 'put',
    data: data
  })
}

// 删除代码生成配置
export function delGen(tableIds: string) {
  return request({
    url: '/tool/gen/' + tableIds,
    method: 'delete'
  })
}

// 预览代码
export function previewCode(tableId: number) {
  return request({
    url: '/tool/gen/preview/' + tableId,
    method: 'get'
  })
}

// 下载代码
export function downloadCode(tableId: number) {
  return request({
    url: '/tool/gen/download/' + tableId,
    method: 'get',
    responseType: 'blob'
  })
}

// 同步数据库
export function synchDb(tableId: number) {
  return request({
    url: '/tool/gen/synchDb/' + tableId,
    method: 'get'
  })
}

// 获取数据源列表
export function getDataNames() {
  return request({
    url: '/tool/gen/getDataNames',
    method: 'get'
  })
}
```
