# 017-代码生成 - 功能规格

**模块编号：** 017  
**模块名称：** 代码生成 (Code Generation)  
**所属模块：** 系统工具  
**版本：** 5.X (RuoYi-Vue-Plus)  
**最后更新：** 2026-03-13

---

## 一、功能概述

代码生成模块是 RuoYi-Vue-Plus 的核心效率工具，用于根据数据库表结构自动生成完整的 CRUD 代码。该模块支持多数据源、多种模板类型（单表、树表），可生成后端 Java 代码、前端 Vue/TS 代码以及数据库脚本，大幅减少重复性开发工作。

### 1.1 核心功能

- **数据源管理**：支持多数据源切换，可从不同数据库导入表结构
- **表导入**：从数据库导入表结构到代码生成配置表
- **代码配置**：配置生成代码的包路径、模块名、作者等信息
- **字段配置**：配置每个字段的 Java 类型、显示类型、查询方式等
- **模板选择**：支持 CRUD 单表、Tree 树表两种模板类型
- **代码预览**：在线预览生成的代码内容
- **代码下载**：下载生成的 ZIP 压缩包
- **自定义路径生成**：直接生成代码到指定项目路径
- **数据库同步**：同步数据库表结构变更到生成配置

### 1.2 与 RuoYi-Vue 的主要差异

| 特性 | RuoYi-Vue | RuoYi-Vue-Plus | 说明 |
|------|-----------|----------------|------|
| **ORM 框架** | MyBatis | MyBatis-Plus | 使用 MP 的 BaseMapperPlus |
| **多数据源** | 不支持 | 支持 | 通过 `@DS` 注解实现 |
| **数据对象** | DO/DTO | BO/VO | 更清晰的分层设计 |
| **字段策略** | 手动配置 | FieldStrategy | MP 字段更新策略 |
| **数据库类型** | MySQL 为主 | 多数据库 | 支持 Oracle、PostgreSQL、SQL Server |
| **元数据获取** | 原生 JDBC | Anyline | 使用 Anyline 元数据框架 |
| **事务管理** | @Transactional | @DSTransactional | 多数据源事务 |

### 1.3 业务规则

1. **表名唯一性**：同一数据源下，表名不能重复导入
2. **数据源隔离**：不同数据源的表结构独立管理
3. **模板匹配**：根据选择的模板类型生成对应的代码结构
4. **字段保留**：同步数据库时保留用户配置的查询方式、字典类型等
5. **逻辑删除**：生成的代码支持逻辑删除（del_flag）
6. **租户隔离**：多租户模式下自动添加 tenant_id 字段
7. **基类字段**：自动继承 BaseEntity（创建者、创建时间等）
8. **代码覆盖保护**：自定义路径生成时不会覆盖已有文件

## 二、功能详细设计

### 2.1 代码生成列表查询

**功能描述：** 分页查询已导入的代码生成配置列表

**查询条件：**
- 数据源名称（下拉选择）
- 表名称（模糊匹配）
- 表描述（模糊匹配）
- 时间范围（创建时间）

**列表字段：**
- 表名称、表描述、实体类名称
- 生成包路径、生成模块名
- 创建时间、更新时间、操作列

**权限标识：** `tool:gen:list`

**API 接口：** `GET /tool/gen/list`

### 2.2 数据库表列表查询

**功能描述：** 查询数据库中未导入的表结构列表

**查询条件：**
- 数据源名称（下拉选择）
- 表名称（模糊匹配）
- 表描述（模糊匹配）

**业务规则：**
1. 过滤掉系统表前缀（sj_、flow_、gen_）
2. 显示已导入的表，但标记为不可选
3. 支持跨数据源查询

**权限标识：** `tool:gen:list`

**API 接口：** `GET /tool/gen/db/list`

### 2.3 导入表结构

**功能描述：** 从数据库导入表结构到代码生成配置

**导入流程：**
1. 选择数据源
2. 选择一个或多个表
3. 系统自动读取表结构和列信息
4. 初始化表配置（类名、包路径等）
5. 初始化列配置（Java 类型、显示类型等）
6. 保存到 gen_table 和 gen_table_column 表

**初始化规则：**
- 表名转类名：下划线转驼峰（user_info → UserInfo）
- 包路径：使用系统配置（org.dromara）
- 模块名：包路径最后一段
- 业务名：表名下划线后部分转驼峰
- 功能名：表描述去除"表"、"若依"等关键字
- 作者：使用系统配置

**字段初始化规则：**
- 字符串类型 → String + Input
- 文本类型（长度≥500）→ String + Textarea
- 时间类型 → Date + Datetime
- 数字类型 → Long + Input
- 状态字段 → Radio 单选
- 类型/性别字段 → Select 下拉
- 图片字段 → ImageUpload
- 文件字段 → FileUpload
- 内容字段 → Editor 富文本

**权限标识：** `tool:gen:import`

**API 接口：** `POST /tool/gen/importTable`

### 2.4 修改代码生成配置

**功能描述：** 修改已导入表的代码生成配置

**可配置字段：**

**表配置：**
- 数据源名称
- 表名称（不可修改）
- 表描述
- 实体类名称
- 模板类型（crud/tree）
- 生成包路径
- 生成模块名
- 生成业务名
- 生成功能名
- 生成作者
- 生成方式（0-ZIP 下载/1-自定义路径）
- 生成路径（自定义路径时填写）
- 上级菜单 ID
- 备注

**字段配置：**
- 列描述
- Java 类型（String/Long/Integer/Date/BigDecimal）
- Java 字段名
- 是否主键
- 是否自增
- 是否必填
- 是否插入字段
- 是否编辑字段
- 是否列表字段
- 是否查询字段
- 查询方式（EQ/NE/GT/LT/LIKE/BETWEEN）
- 显示类型（Input/Textarea/Select/Checkbox/Radio/Datetime）
- 字典类型

**权限标识：** `tool:gen:edit`

**API 接口：** `PUT /tool/gen`

### 2.5 删除代码生成配置

**功能描述：** 删除已导入的代码生成配置

**操作方式：** 支持批量删除（多选表）

**业务规则：**
1. 仅删除配置信息，不删除数据库表
2. 删除时同时删除关联的字段配置
3. 需要权限验证

**权限标识：** `tool:gen:remove`

**API 接口：** `DELETE /tool/gen/{tableIds}`

### 2.6 代码预览

**功能描述：** 在线预览生成的代码内容

**预览内容：**
- Entity 实体类
- Mapper 接口
- Service 接口和实现类
- Controller 控制器
- XML 映射文件
- Vue 页面组件
- API 接口文件
- SQL 脚本

**业务规则：**
1. 根据模板类型生成对应的代码
2. 使用 Velocity 模板引擎渲染
3. 支持多文件切换预览

**权限标识：** `tool:gen:preview`

**API 接口：** `GET /tool/gen/preview/{tableId}`

### 2.7 代码下载

**功能描述：** 下载生成的代码 ZIP 压缩包

**下载内容：**
- 完整的后端代码（Java/XML）
- 完整的前端代码（Vue/TS）
- SQL 脚本（可选）
- README 说明文件

**业务规则：**
1. ZIP 文件以表名命名
2. 包含完整的项目结构
3. 支持批量下载多表代码

**权限标识：** `tool:gen:code`

**API 接口：** `GET /tool/gen/download/{tableId}`

### 2.8 自定义路径生成

**功能描述：** 直接生成代码到指定的项目路径

**生成方式：**
1. 配置生成路径（如：/home/projects/myapp）
2. 系统自动创建目录结构
3. 生成代码到对应位置

**业务规则：**
1. 需要配置允许生成路径
2. 不会覆盖已有文件
3. 生成后需要手动编译和重启

**权限标识：** `tool:gen:code`

**API 接口：** `GET /tool/gen/genCode/{tableId}`

### 2.9 同步数据库

**功能描述：** 同步数据库表结构变更到代码生成配置

**同步内容：**
- 表描述变更
- 字段类型变更
- 新增字段
- 删除字段

**业务规则：**
1. 保留用户配置（查询方式、字典类型等）
2. 新增字段自动添加到配置
3. 删除字段仅标记，不删除配置

**权限标识：** `tool:gen:edit`

**API 接口：** `GET /tool/gen/synchDb/{tableId}`

### 2.10 数据源列表查询

**功能描述：** 获取系统中配置的数据源名称列表

**返回内容：** 数据源名称数组（如：["master", "slave1", "slave2"]）

**业务规则：**
1. 从数据库配置动态读取
2. 支持动态数据源

**权限标识：** `tool:gen:list`

**API 接口：** `GET /tool/gen/getDataNames`

## 三、用户故事

### 3.1 开发人员 - 快速生成 CRUD 代码

**作为** 开发人员  
**我想要** 根据数据库表自动生成 CRUD 代码  
**以便于** 减少重复性编码工作，提高开发效率

**验收标准：**
- 可以选择数据库表导入
- 可以配置生成参数
- 可以预览生成的代码
- 可以下载 ZIP 压缩包

### 3.2 开发人员 - 多数据源支持

**作为** 开发人员  
**我想要** 从不同的数据库导入表结构  
**以便于** 在微服务架构下管理多个数据源的代码生成

**验收标准：**
- 可以切换数据源
- 可以查询不同数据源的表
- 生成的代码支持多数据源注解

### 3.3 开发人员 - 自定义代码路径

**作为** 开发人员  
**我想要** 直接生成代码到项目路径  
**以便于** 快速集成到现有项目中

**验收标准：**
- 可以配置生成路径
- 生成的代码符合项目结构
- 不会覆盖已有文件

### 3.4 开发人员 - 树表模板支持

**作为** 开发人员  
**我想要** 使用树表模板生成层级结构代码  
**以便于** 快速实现部门、菜单等树形数据管理

**验收标准：**
- 可以选择树表模板
- 生成树形结构的 Entity 和 Mapper
- 生成树形组件的前端代码

## 四、验收场景

### 4.1 导入表结构

**场景：** 从数据库导入单表

**给定** 系统已配置数据源  
**当** 用户选择一个表并点击导入  
**那么** 系统自动创建 gen_table 和 gen_table_column 记录  
**并且** 初始化类名、包路径、字段类型等配置

### 4.2 生成代码下载

**场景：** 下载生成的代码 ZIP

**给定** 已导入并配置好表结构  
**当** 用户点击"下载代码"按钮  
**那么** 系统生成 ZIP 文件  
**并且** 浏览器开始下载  
**并且** ZIP 包含完整的 Java、Vue、SQL 文件

### 4.3 同步数据库变更

**场景：** 数据库表结构变更后同步

**给定** 已导入的表在数据库中修改了字段  
**当** 用户点击"同步数据库"  
**那么** 系统读取最新的表结构  
**并且** 保留用户配置的查询方式、字典类型  
**并且** 更新字段配置信息

## 五、技术实现要点

### 5.1 核心组件

- **GenController**：REST API 控制器
- **IGenTableService**：业务服务接口
- **GenTableServiceImpl**：业务服务实现
- **GenTable/GenTableColumn**：领域模型
- **GenTableMapper/GenTableColumnMapper**：数据访问层

### 5.2 模板引擎

- **Apache Velocity**：代码模板渲染
- **模板位置**：resources/vm/
- **模板类型**：java、xml、vue、sql、js

### 5.3 多数据源支持

- **@DS 注解**：动态数据源切换
- **DataBaseHelper**：数据库元数据获取
- **Anyline**：跨数据库元数据框架

### 5.4 安全控制

- **Sa-Token 权限**：接口权限验证
- **@Lock4j 分布式锁**：防止并发导入/同步
- **@RepeatSubmit**：防重复提交
