## 一、用户角色

| 角色 | 说明 | 核心需求 |
|------|------|---------|
| 后端开发人员 | 负责业务代码开发 | 快速生成 CRUD 代码，减少重复工作 |

## 二、用户故事列表

### US-001：导入数据库表结构

**作为** 开发人员  
**我想要** 从数据库导入表结构到代码生成系统  
**以便于** 基于表结构生成代码

**验收标准：**
- [ ] 可以选择数据源
- [ ] 可以查看数据库表列表
- [ ] 支持多选表导入
- [ ] 已导入的表显示为禁用状态
- [ ] 导入后自动初始化表配置和字段配置
- [ ] 导入成功后在列表中显示

**优先级：** P0 - 高  
**估算点数：** 5

---

### US-002：配置代码生成参数

**作为** 开发人员  
**我想要** 配置生成代码的包路径、模块名等参数  
**以便于** 生成的代码符合项目结构

**验收标准：**
- [ ] 可以修改表描述、实体类名
- [ ] 可以配置包路径（如：org.dromara）
- [ ] 可以配置模块名（如：system）
- [ ] 可以配置业务名（如：user）
- [ ] 可以配置功能名和作者
- [ ] 可以选择模板类型（CRUD/树表）
- [ ] 可以选择生成方式（ZIP/自定义路径）
- [ ] 配置保存后生效

**优先级：** P0 - 高  
**估算点数：** 5

## 五、验收场景

### 场景 1：导入单表并生成代码

**给定** 系统已配置数据源  
**当** 开发人员选择一个表并导入  
**并且** 配置表信息和字段属性  
**并且** 点击"下载代码"  
**那么** 浏览器下载包含完整代码的 ZIP 文件  
**并且** ZIP 包含 Entity、Mapper、Service、Controller、Vue 等文件

---

### 场景 2：批量生成多个模块代码

**给定** 已导入多个表  
**当** 开发人员选择多个表  
**并且** 点击"批量生成"  
**那么** 下载包含所有选中表代码的 ZIP 文件  
**并且** 代码按模块分目录组织

---

### 场景 3：同步数据库变更

**给定** 已导入的表在数据库中新增了字段  
**当** 开发人员点击"同步数据库"  
**那么** 系统读取最新的表结构  
**并且** 保留用户配置的查询方式、字典类型  
**并且** 新增字段自动添加到配置  
**并且** 提示同步成功

---

### 场景 4：使用树表模板生成代码

**给定** 有一个树形结构的表（如部门表）  
**当** 开发人员选择"树表"模板类型  
**并且** 配置树编码、树父编码、树名称  
**并且** 生成代码  
**那么** 生成的 Entity 包含树形属性  
**并且** 生成的 Mapper 包含树形查询方法  
**并且** 生成的前端包含树形组件

## 六、依赖与风险

### 依赖

- 数据库连接配置
- Velocity 模板引擎
- 前端 Element Plus 组件库

### 风险

1. **模板复杂度**：主子表模板实现复杂度高
2. **数据库兼容性**：不同数据库的元数据获取方式不同
3. **代码覆盖**：自定义路径生成时可能覆盖已有文件
