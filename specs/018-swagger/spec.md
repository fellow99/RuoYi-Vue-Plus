## 一、功能概述

API 文档模块为 RuoYi-Vue-Plus 提供自动化的 API 接口文档生成功能。基于 SpringDoc OpenAPI（Swagger 3.0）规范，自动扫描项目中的 REST API 接口，生成可视化的接口文档，支持在线调试和测试。

### 1.1 核心功能

- **自动扫描**：自动扫描项目中的 REST API 接口
- **文档生成**：生成符合 OpenAPI 3.0 规范的接口文档
- **在线调试**：支持在线测试 API 接口
- **认证集成**：集成 Sa-Token 认证
- **分组管理**：支持按模块分组显示
- **数据模型**：自动展示请求/响应数据结构
- **上下文路径**：自动适配项目上下文路径

### 1.2 与 RuoYi-Vue 的主要差异

| 特性 | RuoYi-Vue | RuoYi-Vue-Plus | 说明 |
|------|-----------|----------------|------|
| **文档框架** | Swagger 2.0 | SpringDoc OpenAPI 3.0 | 更现代的 API 文档标准 |
| **UI 界面** | Swagger UI | SpringDoc UI | 更简洁的界面 |
| **注解支持** | @ApiOperation | @Operation | 使用 Jakarta 标准 |
| **上下文路径** | 手动配置 | 自动适配 | 自动添加项目上下文路径 |
| **认证方式** | JWT | Sa-Token | 集成 Sa-Token 认证 |

### 1.3 业务规则

1. **接口可见性**：仅扫描公开的 REST API 接口
2. **权限标识**：自动显示接口的权限标识
3. **分组规则**：按 Controller 的 RequestMapping 路径分组
4. **数据模型**：自动解析请求/响应的数据结构
5. **生产环境**：生产环境默认关闭文档功能

## 二、功能详细设计

### 2.1 接口文档访问

**功能描述：** 通过浏览器访问 API 文档页面

**访问地址：**
- 开发环境：`http://localhost:8080/doc.html`
- 生产环境：默认关闭（需配置开启）

**业务规则：**
1. 仅认证用户可访问
2. 支持按模块筛选接口
3. 支持搜索接口

### 2.2 接口自动扫描

**功能描述：** 自动扫描项目中的 REST API 接口

**扫描范围：**
- `@RestController` 注解的类
- `@RequestMapping` 及其变体注解的方法
- 排除内部接口和健康检查接口

**业务规则：**
1. 自动识别 GET/POST/PUT/DELETE 等方法
2. 自动解析请求参数和响应类型
3. 自动识别权限标识

### 2.3 接口文档配置

**功能描述：** 配置 API 文档的基本信息

**可配置项：**
- 文档标题
- 文档描述
- 版本信息
- 联系人信息
- 许可证信息
- 服务条款

**配置方式：** application.yml 配置文件

### 2.4 接口在线调试

**功能描述：** 在文档页面直接测试 API 接口

**支持操作：**
- 填写请求参数
- 设置请求头
- 发送请求
- 查看响应结果

**业务规则：**
1. 自动携带认证 Token
2. 支持文件上传测试
3. 支持复杂 JSON 数据

### 2.5 数据模型展示

**功能描述：** 展示 API 接口使用的数据模型

**展示内容：**
- 请求体结构
- 响应体结构
- 字段类型和说明
- 必填/可选标识

**业务规则：**
1. 自动解析泛型类型
2. 支持嵌套对象展示
3. 支持枚举类型展示

### 2.6 认证集成

**功能描述：** 集成 Sa-Token 认证

**认证方式：**
- Token 认证（Header 方式）
- 自动携带 Token

**业务规则：**
1. 未认证接口标记为公开
2. 需认证接口显示认证要求
3. 支持 Token 刷新

## 五、技术实现要点

### 5.1 核心组件

- **SpringDocConfig**：文档配置类
- **OpenApiHandler**：OpenAPI 处理器
- **SpringDocProperties**：文档配置属性
- **PlusPaths**：自定义路径处理器

### 5.2 依赖库

- **springdoc-openapi-starter-webmvc-ui**：SpringDoc 核心
- **sa-token**：认证集成
- **knife4j**：增强 UI（可选）

### 5.3 注解使用

```java
// 接口文档注解
@Operation(summary = "接口描述")
@ApiResponses({
    @ApiResponse(responseCode = "200", description = "成功")
})
@Parameter(description = "参数描述")
```

### 5.4 配置管理

```yaml
springdoc:
  api-docs:
    enabled: true
    path: /v3/api-docs
  swagger-ui:
    enabled: true
    path: /swagger-ui.html
```

## 六、依赖与约束

### 6.1 外部依赖

- Spring Boot 3.x
- SpringDoc OpenAPI
- Sa-Token

### 6.2 配置要求

- 开发环境开启文档
- 生产环境关闭文档
- 配置文档基本信息

### 6.3 安全要求

- 生产环境必须关闭文档
- 敏感接口不显示在文档中
- 认证信息不暴露在文档中
