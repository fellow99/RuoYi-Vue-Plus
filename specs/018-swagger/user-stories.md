## 五、验收场景

### 场景 1：前端开发查看接口文档

**给定** 系统已启动并运行  
**当** 前端开发人员访问 `/doc.html`  
**那么** 显示 API 文档页面  
**并且** 显示所有接口列表  
**并且** 可以按模块筛选  
**并且** 可以搜索接口

---

### 场景 2：测试人员测试用户接口

**给定** 测试人员已登录系统  
**当** 测试人员找到用户管理接口  
**并且** 点击"Try it out"  
**并且** 填写查询参数  
**并且** 点击"Execute"  
**那么** 显示请求详情  
**并且** 显示响应结果  
**并且** 响应包含用户列表数据

---

### 场景 3：配置认证 Token

**给定** 用户已获取 Token  
**当** 用户点击"Authorize"按钮  
**并且** 输入 Token  
**并且** 点击"Authorize"保存  
**那么** Token 保存到会话  
**并且** 所有请求自动携带 Token  
**并且** 可以成功访问需认证的接口

---

### 场景 4：查看数据模型

**给定** 用户打开用户详情接口  
**当** 用户查看数据模型部分  
**那么** 显示 SysUser 对象结构  
**并且** 显示所有字段类型  
**并且** 显示字段说明  
**并且** 显示枚举值（如状态）

## 六、依赖与风险

### 依赖

- Spring Boot 3.x
- SpringDoc OpenAPI
- Sa-Token 认证

### 风险

1. **性能问题**：接口数量多时加载慢
   - 缓解：按需加载，使用搜索功能

2. **安全问题**：生产环境暴露文档
   - 缓解：生产环境默认关闭文档

3. **文档准确性**：代码更新文档未更新
   - 缓解：自动生成，减少手动维护

---

## 七、最佳实践

### 7.1 文档编写

- 所有接口添加描述
- 所有参数添加说明
- 所有数据模型添加注解
- 重要接口添加示例

### 7.2 安全配置

- 生产环境关闭文档
- 敏感接口不显示
- 认证信息不暴露

### 7.3 性能优化

- 按需加载接口
- 使用搜索功能
- 避免频繁刷新
