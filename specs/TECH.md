## 一、技术栈概览

RuoYi-Vue-Plus 是针对分布式集群与多租户场景全方位重写的企业级快速开发平台，基于 Spring Boot 3.5 + JDK 17/21 构建。

### 架构模式
- **架构风格：** 前后端分离 + 插件化模块设计
- **后端架构：** Spring Boot 分层架构 + 多租户架构
- **前端架构：** Vue3 + TypeScript + Element Plus
- **通信协议：** HTTP/HTTPS + RESTful API + WebSocket + SSE
- **数据格式：** JSON

## 五、技术选型理由

### 5.1 为什么选择 Spring Boot 3.5?
- **最新特性：** 支持 Java 17/21 新特性
- **性能提升：** 相比 2.x 版本性能大幅提升
- **生态完善：** 丰富的 Starter 依赖
- **微服务友好：** 易于向 Spring Cloud 迁移

### 5.2 为什么选择 Sa-Token?
- **功能齐全：** 支持登录校验、角色校验、权限校验、二级认证等
- **低耦合：** 静态使用，不侵入业务代码
- **高扩展：** 易于扩展自定义权限逻辑
- **表达式丰富：** 支持 AND、OR 等复杂权限表达式

### 5.3 为什么选择 MyBatis-Plus?
- **对象化操作：** 基于对象几乎不用写 SQL
- **插件丰富：** 多租户插件、分页插件、乐观锁插件等
- **功能强大：** 支持动态 SQL、条件构造器
- **学习成本低：** 文档完善，易于上手

### 5.4 为什么选择 Redisson?
- **功能全面：** 支持 Redis 90% 以上的命令
- **性能优化：** 基于 Netty，底层优化规避不正确用法
- **模式丰富：** 支持单机、哨兵、单主集群、多主集群等模式
- **官方推荐：** Redis 官方推荐客户端

### 5.5 为什么选择 MinIO?
- **分布式存储：** 天生支持多机、多硬盘、多分片、多副本
- **权限管理：** 支持权限管理，安全可靠
- **加密存储：** 文件可加密存储
- **高性能：** 对象存储性能优异

### 5.6 为什么选择 SnailJob?
- **分布式支持：** 天生支持分布式，无需额外配置
- **统一管理：** 统一的管理中心
- **功能丰富：** 支持分片、重试、DAG 任务流等
- **多数据库支持：** 支持多种数据库作为存储

### 5.7 为什么选择多租户架构?
- **SaaS 友好：** 适合 SaaS 平台开发
- **数据隔离：** 租户数据自动隔离，安全可靠
- **灵活配置：** 支持租户套餐、过期时间、用户数量等管理
- **无感切换：** 基于 MyBatis-Plus 插件，业务代码无感知

### 5.8 为什么选择插件化模块设计?
- **结构解耦：** 模块间低耦合，易于维护
- **易于扩展：** 插件化设计，易于扩展新功能
- **独立部署：** 支持模块独立部署
- **按需加载：** 可根据需求加载模块
