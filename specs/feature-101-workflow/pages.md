## 一、页面概述

工作流模块包含以下主要页面：

| 页面名称 | 路由路径 | 权限标识 | 说明 |
|---------|---------|---------|------|
| 流程分类 | `/workflow/category` | `workflow:category:list` | 流程分类管理 |
| 流程定义 | `/workflow/definition` | `workflow:definition:list` | 流程定义管理 |
| 流程实例 | `/workflow/instance` | `workflow:instance:list` | 流程实例管理 |
| 我的待办 | `/workflow/task/todo` | `workflow:task:list` | 用户待办任务 |
| 我的已办 | `/workflow/task/done` | `workflow:task:list` | 用户已办任务 |
| 流程历史 | `/workflow/task/history` | `workflow:task:list` | 流程历史记录 |
| 流程设计 | `/workflow/designer` | `workflow:definition:add` | 流程设计器 |

## 二、页面详细设计

### 2.1 流程分类管理页

**路由：** `/workflow/category`

**功能：**
- 分类列表展示（表格）
- 新增分类（弹窗）
- 编辑分类（弹窗）
- 删除分类（确认对话框）
- 分类启用/停用

**UI 组件：**
- 表格：展示分类列表
- 表单弹窗：新增/编辑分类
- 状态开关：启用/停用

---

### 2.2 流程定义管理页

**路由：** `/workflow/definition`

**功能：**
- 定义列表展示
- 导入 BPMN 文件（文件上传）
- 导出 BPMN 文件
- 发布/部署流程
- 查看流程图
- 版本管理
- 删除定义

**UI 组件：**
- 表格：展示定义列表
- 文件上传：导入 BPMN
- 对话框：查看流程图
- 版本列表：展示历史版本

---

### 2.3 流程实例管理页

**路由：** `/workflow/instance`

**功能：**
- 运行中实例列表
- 已结束实例列表
- 实例详情查看
- 取消实例
- 作废实例
- 流程追踪（查看流程图和当前节点）

**UI 组件：**
- 标签页：切换运行中/已结束
- 表格：展示实例列表
- 详情对话框：展示实例信息
- 流程图：高亮显示当前节点

---

### 2.4 我的待办页

**路由：** `/workflow/task/todo`

**功能：**
- 待办任务列表
- 任务筛选（按流程、按时间）
- 办理任务（弹窗）
- 任务详情查看

**UI 组件：**
- 表格：展示待办任务
- 筛选表单：流程名称、时间范围
- 办理弹窗：填写意见、选择操作

---

### 2.5 我的已办页

**路由：** `/workflow/task/done`

**功能：**
- 已办任务列表
- 任务筛选
- 查看办理历史

**UI 组件：**
- 表格：展示已办任务
- 筛选表单：流程名称、时间范围

---

### 2.6 流程历史页

**路由：** `/workflow/task/history`

**功能：**
- 历史任务列表
- 任务详情查看
- 流程追踪

**UI 组件：**
- 表格：展示历史任务
- 详情对话框：展示任务信息

---

### 2.7 流程设计器页

**路由：** `/workflow/designer`

**功能：**
- 可视化流程设计
- 节点配置
- 连线配置
- 表单绑定
- BPMN 预览

**UI 组件：**
- 流程设计器：基于 bpmn.js 或类似库
- 属性面板：节点属性配置
- 工具栏：保存、发布、预览

## 三、页面交互流程

### 3.1 发起流程

```
用户点击"发起流程" 
  → 选择流程定义 
  → 填写表单数据 
  → 提交 
  → 系统创建流程实例 
  → 显示提交成功和当前任务信息
```

### 3.2 办理任务

```
用户进入"我的待办" 
  → 点击待办任务 
  → 查看任务详情和表单 
  → 填写办理意见 
  → 选择操作（同意/拒绝/转办等） 
  → 提交 
  → 系统更新任务状态 
  → 显示办理成功
```

### 3.3 流程追踪

```
用户查看流程实例 
  → 点击"流程追踪" 
  → 显示流程图（高亮当前节点） 
  → 显示各节点处理记录 
  → 显示流程变量
```

---

## 四、响应式设计

- 表格支持响应式布局，在小屏幕上显示滚动条
- 弹窗适配移动端，全屏显示
- 流程图支持缩放和拖拽
