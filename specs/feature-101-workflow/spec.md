# feature-101 工作流模块 - 功能规格

**模块编号：** feature-101  
**模块名称：** 工作流模块 (Workflow)  
**所属模块：** RuoYi-Vue-Plus 增强特性  
**版本：** 5.5.3 (RuoYi-Vue-Plus)  
**技术栈：** Warm-Flow 工作流引擎  
**最后更新：** 2026-03-13

---

## 一、功能概述

工作流模块基于 Warm-Flow 轻量级工作流引擎，为 RuoYi-Vue-Plus 提供完整的流程管理能力。该模块支持流程定义、流程实例、任务管理等核心功能，适用于各类审批场景。

### 1.1 核心功能

- **流程分类管理**：对流程定义进行分类管理，便于组织和检索
- **流程定义管理**：流程的导入、导出、发布、部署、版本管理
- **流程实例管理**：流程实例的启动、查询、取消、作废
- **任务管理**：待办任务、已办任务、任务办理、任务委派、任务转办
- **流程变量**：流程运行时变量的设置和查询
- **SPeL 表达式**：支持使用 SPeL 表达式进行流程条件判断
- **按钮权限**：流程节点按钮级别的权限控制
- **消息通知**：任务到达、任务超时等消息通知

### 1.2 技术特性

- **Warm-Flow 引擎**：轻量级、高性能的国产工作流引擎
- **MyBatis-Plus 集成**：无缝集成 RuoYi-Vue-Plus 的数据访问层
- **Sa-Token 权限**：基于 Sa-Token 的任务权限控制
- **Redis 缓存**：流程数据缓存，提升查询性能
- **多租户支持**：基于 ruoyi-common-tenant 的租户隔离

## 二、与 RuoYi-Vue 的差异

| 差异点 | RuoYi-Vue | RuoYi-Vue-Plus |
|-------|-----------|----------------|
| 工作流引擎 | 不支持 / Activiti | Warm-Flow (轻量级) |
| 流程定义 | - | 支持导入导出、版本管理 |
| 流程实例 | - | 支持业务关联、状态追踪 |

| 按钮权限 | - | 节点级别按钮权限控制 |
| 消息通知 | - | 任务消息通知 |
| 数据隔离 | - | 多租户数据隔离 |

## 三、功能详细设计

### 3.1 流程分类管理

**功能描述：** 对流程定义进行分类管理

**查询条件：**
- 分类名称（模糊匹配）
- 分类状态（0-正常 / 1-停用）

**列表字段：**
- 分类 ID、分类名称、分类编码
- 排序、状态、备注、创建时间

**权限标识：** workflow:category:list

### 3.2 流程定义管理

**功能描述：** 管理流程定义的完整生命周期

**核心操作：**
- **导入流程**：上传 BPMN 流程文件
- **导出流程**：导出流程定义为 BPMN 文件
- **发布流程**：将流程定义发布为可用状态
- **部署流程**：部署流程到引擎
- **版本管理**：查看和管理流程版本
- **删除流程**：删除未发布的流程定义

**权限标识：** workflow:definition:list/query/add/edit/remove

### 3.3 流程实例管理

**功能描述：** 管理运行中和已结束的流程实例

**查询条件：**
- 流程定义 ID
- 流程实例 ID
- 业务 ID
- 流程状态（运行中/已结束）
- 时间范围

**列表字段：**
- 实例 ID、流程定义名称、业务 ID
- 发起人、发起时间、结束时间
- 流程状态、操作列

**核心操作：**
- **启动实例**：根据流程定义启动新实例
- **取消实例**：取消运行中的流程实例
- **作废实例**：作废已结束的流程实例
- **查询详情**：查看流程实例详细信息和流程图

**权限标识：** workflow:instance:list/query/cancel/invalid

### 3.4 任务管理

**功能描述：** 管理用户的工作任务

**待办任务：**
- 查询当前用户的待办任务
- 支持按流程定义、任务名称筛选
- 显示任务优先级、到达时间

**已办任务：**
- 查询当前用户的已办任务
- 显示办理时间、办理意见

**任务操作：**
- **办理任务**：完成任务并填写意见
- **委派任务**：将任务委派给其他用户
- **转办任务**：将任务转交给其他用户
- **催办任务**：向任务处理人发送催办通知
- **回退任务**：将任务回退到上一个节点
- **驳回任务**：将任务驳回到发起人

**权限标识：** workflow:task:list/complete/delegate/transfer/urge/back/reject

### 3.5 流程变量

**功能描述：** 管理流程运行时变量

**功能：**
- 设置流程变量
- 查询流程变量
- 删除流程变量

**权限标识：** workflow:variable:set/query/remove

### 3.6 SPeL 表达式

**功能描述：** 管理流程中使用的 SPeL 表达式

**功能：**
- 新增表达式
- 修改表达式
- 删除表达式
- 测试表达式

**权限标识：** workflow:spel:list/add/edit/remove

## 四、业务规则

1. **流程定义唯一性**：流程定义 Key 在系统中必须唯一
2. **版本管理**：同一流程定义 Key 可以有多个版本，发布时自动生成新版本号
3. **实例关联**：流程实例必须关联业务 ID，便于业务系统追踪
4. **任务权限**：用户只能查看和操作分配给自己的任务
5. **办理意见**：任务办理时必须填写办理意见
6. **流程取消**：只有流程发起人或管理员可以取消流程实例
7. **数据权限**：基于部门的数据范围控制，用户只能查看权限范围内的流程数据

## 五、成功标准

1. 能够正确导入和解析 BPMN 2.0 流程文件
2. 流程实例能够正确启动和流转
3. 任务能够正确分配给目标用户
4. 支持常见的任务操作（办理、委派、转办、回退、驳回）
5. 流程数据正确持久化到数据库
6. 支持多租户数据隔离
7. 性能指标：流程启动 < 500ms，任务查询 < 300ms
