# 工作流管理功能规格 (spec.md)

> 模块：feature-101-workflow | 状态：已实现 | 最后更新：2026-08-10

## 1. 模块概述

### 1.1 目的
集成 Warm-Flow 工作流引擎，提供流程定义管理、任务办理、流程实例管理、流程分类和 SpEL 表达式管理等功能，支持审批、转办、委派、加减签、会签、或签等复杂流程操作。

### 1.2 范围
- ✅ 流程定义 CRUD、发布/取消发布、导入/导出
- ✅ 流程任务：启动/办理/驳回/转办/委派/加减签/催办/终止
- ✅ 流程实例：运行中/已完成实例管理、撤销/作废/激活
- ✅ 流程分类管理（树形结构）
- ✅ SpEL 表达式管理
- ✅ 请假示例（TestLeave）

## 2. 用户故事
- 作为**管理员**，我可以定义和发布审批流程
- 作为**审批人**，我可以查看待办任务并办理审批
- 作为**申请人**，我可以发起流程并跟踪审批进度
- 作为**管理员**，我可以转办任务、委派任务、加减签

## 3. 功能需求
- FR-101-001: 系统 MUST 支持流程定义的 CRUD 和发布管理
- FR-101-002: 系统 MUST 支持流程任务的启动、办理、驳回
- FR-101-003: 系统 SHOULD 支持转办、委派、加减签等高级操作
- FR-101-004: 系统 MUST 支持待办/已办任务查询
- FR-101-005: 系统 MUST 支持流程实例的生命周期管理

## 4. 关键实体

| 实体 | 说明 |
|------|------|
| FlwCategory | 流程分类 (flow_category) |
| FlwInstance | 流程实例 (扩展信息 flow_instance_biz_ext) |
| FlwSpel | SpEL 表达式 (flow_spel) |

## 5. 依赖
- Warm-Flow 1.8.9
- LiteFlow 2.16.0（规则链编排）
- ruoyi-system（用户/角色/部门查询）
