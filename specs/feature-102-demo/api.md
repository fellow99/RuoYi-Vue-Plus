## 三、接口详细定义

### 3.1 列表查询

**接口：** `GET /list`

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| pageNum | Integer | 否 | 页码 |
| pageSize | Integer | 否 | 每页数量 |

**响应示例：**

```json
{
  "code": 200,
  "msg": "查询成功",
  "rows": [],
  "total": 0
}
```
