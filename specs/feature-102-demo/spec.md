## 一、功能概述

示例模块是 RuoYi-Vue-Plus 的功能演示模块，用于展示框架的各种特性和最佳实践。该模块包含多个示例，涵盖 Redis 使用、加密、数据脱敏、Excel 导入导出、WebSocket、SMS、邮件等功能的示例代码。

### 1.1 核心功能

- **Redis 示例**：缓存、分布式锁、发布订阅、限流器示例
- **加密示例**：接口加密、数据加密解密示例
- **数据脱敏示例**：敏感数据脱敏展示
- **Excel 示例**：Excel 导入导出功能演示
- **WebSocket 示例**：WebSocket 实时通信演示
- **队列示例**：有界队列、延迟队列、优先级队列示例
- **批量处理示例**：批量操作演示
- **树形结构示例**：树形数据处理示例
- **国际化示例**：i18n 多语言支持示例
- **API 文档示例**：Swagger3 API 文档示例

### 1.2 技术特性

- **演示性质**：仅供学习和参考，生产环境请谨慎使用
- **代码示例**：展示 RuoYi-Vue-Plus 各项特性的正确用法
- **最佳实践**：遵循框架推荐的最佳实践
