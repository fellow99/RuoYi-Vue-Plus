# feature-106 幂等模块 - 功能规格

**模块编号：** feature-106  
**模块名称：** 幂等模块 (Idempotent)  
**所属模块：** RuoYi-Vue-Plus 公共模块  
**版本：** 5.5.3 (RuoYi-Vue-Plus)  
**最后更新：** 2026-03-13

---

## 一、功能概述

幂等模块提供接口幂等性保证，防止重复提交导致的重复数据处理。

### 1.1 核心功能

- **重复提交防护**：防止用户重复提交表单
- **Token 机制**：基于 Token 的幂等验证
- **锁机制**：基于 Redis 锁的幂等保证
- **注解支持**：@RepeatSubmit 注解标记幂等接口

### 1.2 技术特性

- **Redis 实现**：基于 Redis 存储 Token
- **自动验证**：拦截器自动验证幂等性
- **自定义间隔**：可配置重复提交时间间隔
- **提示信息**：自定义重复提交提示

---

## 二、功能详细设计

### 2.1 重复提交防护

**功能描述：** 防止接口被重复调用

### 2.2 Token 管理

**功能描述：** 获取和验证幂等 Token

---

## 三、业务规则

1. 幂等接口需要客户端传递 Token
2. Token 一次性使用
3. 超过时间间隔可重新提交
