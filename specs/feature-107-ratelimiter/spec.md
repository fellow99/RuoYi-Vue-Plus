# feature-107 限流模块 - 功能规格

**模块编号：** feature-107  
**模块名称：** 限流模块 (RateLimiter)  
**所属模块：** RuoYi-Vue-Plus 公共模块  
**版本：** 5.5.3 (RuoYi-Vue-Plus)  
**最后更新：** 2026-03-13

---

## 一、功能概述

限流模块提供接口限流功能，防止恶意请求和系统过载。

### 1.1 核心功能

- **接口限流**：限制接口访问频率
- **用户限流**：限制单用户访问频率
- **IP 限流**：限制单 IP 访问频率
- **注解支持**：@RateLimiter 注解标记限流接口

### 1.2 技术特性

- **Redis 实现**：基于 Redis 的限流算法
- **多种算法**：支持固定窗口、滑动窗口、令牌桶
- **自定义配置**：可配置限流参数
- **友好提示**：限流时返回友好提示
