# feature-109 社交登录模块 - 功能规格

**模块编号：** feature-109  
**模块名称：** 社交登录模块 (Social)  
**所属模块：** RuoYi-Vue-Plus 公共模块  
**版本：** 5.5.3 (RuoYi-Vue-Plus)  
**最后更新：** 2026-03-13

---

## 一、功能概述

社交登录模块提供第三方社交账号登录功能。

### 1.1 核心功能

- **微信登录**：支持微信扫码登录
- **QQ 登录**：支持 QQ 登录
- **GitHub 登录**：支持 GitHub 登录
- **账号绑定**：社交账号与系统账号绑定
- **账号解绑**：解除社交账号绑定

### 1.2 技术特性

- **JustAuth 集成**：基于 JustAuth 实现
- **多 Provider 支持**：支持多家第三方平台
- **自动注册**：新用户自动注册
- **账号关联**：支持多社交账号关联同一用户

---

## 二、功能详细设计

### 2.1 社交登录

**功能描述：** 使用社交账号登录

### 2.2 账号绑定

**功能描述：** 绑定社交账号到系统账号

---

## 三、业务规则

1. 需要配置第三方应用信息
2. 一个社交账号只能绑定一个系统账号
3. 系统账号可以绑定多个社交账号
