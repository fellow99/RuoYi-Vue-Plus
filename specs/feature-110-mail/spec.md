## 一、功能概述

邮件模块提供邮件发送功能，支持 HTML 邮件、附件邮件等。

### 1.1 核心功能

- **简单邮件**：发送纯文本邮件
- **HTML 邮件**：发送 HTML 格式邮件
- **附件邮件**：发送带附件的邮件
- **模板邮件**：使用模板发送邮件
- **群发邮件**：批量发送邮件

### 1.2 技术特性

- **Spring Mail 集成**：基于 Spring Mail 实现
- **异步发送**：支持异步发送邮件
- **模板引擎**：支持 Thymeleaf 模板
- **发送记录**：记录邮件发送历史
