## 一、功能概述

WebSocket 模块提供 WebSocket 实时通信能力，支持消息推送、实时通知等功能。

### 1.1 核心功能

- **WebSocket 连接**：建立 WebSocket 连接
- **消息推送**：向指定用户推送消息
- **群发消息**：向所有在线用户广播
- **连接管理**：管理 WebSocket 连接状态
- **心跳检测**：保持连接活跃

### 1.2 技术特性

- **Spring WebSocket 集成**：基于 Spring WebSocket 实现
- **集群支持**：支持集群环境消息推送
- **Redis  PubSub**：使用 Redis 实现集群消息同步
- **连接认证**：WebSocket 连接时进行身份认证

1. 连接需要身份认证
2. 支持断线重连
