## 一、系统概述

### 1.1 系统定位

RuoYi-Vue-Plus v6.0.0 是针对 RuoYi-Vue 进行全方位重写的分布式集群快速开发平台，采用插件化架构设计，基于 **Spring Boot 4.1 + JDK 21** 构建。v6 相比 v5 移除了多租户功能，新增 AI 集成、LiteFlow 规则引擎、MQTT 协议、MCP 协议、消息推送、Elasticsearch 等模块，提供更纯粹的企业级分布式开发底座。

### 1.2 与 RuoYi-Vue 的核心差异

| 维度 | RuoYi-Vue | RuoYi-Vue-Plus v6 |
|------|-----------|-------------------|
| 前端框架 | Vue2/Vue3 + JS | Vue3 + TypeScript + Element Plus |
| 后端架构 | 模块耦合 | 插件化解耦（25 个 common 子模块） |
| 权限认证 | Spring Security | Sa-Token + JWT |
| ORM 框架 | MyBatis (XML) | MyBatis-Plus（对象化操作） |
| Web 容器 | Tomcat | Jetty 12 (Netty) |
| 序列化 | Fastjson | Jackson |
| 分布式锁 | ❌ | Lock4j + Redisson |
| 任务调度 | Quartz | SnailJob（分布式原生） |
| 文件存储 | 本地文件 | MinIO + RustFS + S3 |
| AI 集成 | ❌ | Spring AI 2.0 + SnailAI + MCP |
| 数据脱敏 | ❌ | 注解 + 序列化 |
| 数据加解密 | ❌ | 注解 + MyBatis 拦截器 |
| 接口加密 | ❌ | 动态 AES + RSA |
| 数据翻译 | ❌ | 注解 + 动态翻译 |

### 1.3 目标用户

- **超级管理员** — 系统最高权限，管理系统所有资源
- **普通管理员** — 部门或模块管理员，拥有部分管理权限
- **普通用户** — 日常业务操作、信息查询
- **开发人员** — 基于框架进行二次开发

### 1.4 核心价值

1. **快速开发** — 提供通用功能模块，减少重复开发
2. **权限完善** — 细粒度权限控制，支持数据权限
3. **易于扩展** — 插件化设计，按需引入模块
4. **开箱即用** — 内置常用功能，配置即可使用
5. **分布式就绪** — 原生支持集群、分布式锁、分布式任务
6. **AI 原生** — Spring AI 深度集成，MCP 协议支持

## 三、非功能性需求

### 3.1 性能
- 核心 API 响应时间 < 500ms（P95）
- 支持 10,000+ 并发用户
- Redis 缓存命中率 > 90%
- 数据库连接池合理配置（默认 20 最大连接）

### 3.2 可用性
- 支持集群部署，无状态设计，水平扩展
- JWT 无状态认证，单点故障不影响
- 数据库主从读写分离（Dynamic-Datasource）

### 3.3 安全性
- JWT + Sa-Token 双重认证
- 接口传输动态 AES + RSA 加密
- 敏感字段加解密存储
- XSS 过滤、SQL 注入防护
- 接口幂等、接口限流

### 3.4 可维护性
- 模块化设计，低耦合高内聚
- 统一代码风格（Alibaba 规范）
- 完善的 JavaDoc + SpringDoc API 文档
- Docker 一键部署

### 3.5 国际化
- 基于请求头的多语言返回
- 校验注解国际化
- i18n 资源文件（中文/英文）
